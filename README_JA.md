## 7ステップのデモ：2分で実際のリストをティア分けし、最初のアウトリーチを書く

先にドキュメントを読む必要はありません。7ステップ、それぞれ説明1行、コピペできるコマンド1つ。最初から最後まで約2分です。以下の7つのコマンドは、すべてこのリポジトリで実際に実行済みです（2026-11-24、Python 3.x、標準ライブラリのみ）。サンプルデータは架空で、会社名には 【示例】（「サンプル」）の接頭辞が付いています。

| ステップ | ひとことで | コマンド（コピペ用） |
|---|---|---|
| 1 リストを用意 | サンプルを自分用のファイルにコピー。実際のリードはこのコピーにだけ入れる | `cp examples/leads_example.csv my_leads.csv` |
| 2 ティア分け | 10件のリードをT0〜T3に分類。今日はそのうち2件に連絡 | `python scripts/lead_score.py my_leads.csv` |
| 3 T0を精査 | 書き始める前に、T0がペーパーカンパニーでないか確認。あなたが入力しなかった項目は「要確認」で返ってくる | `python scripts/due_diligence.py --company "【示例】海湾轮胎贸易"` |
| 4 初回コンタクトを書く | T0ティア向けのアウトリーチ下書き。英語は送信用、中国語はご自身の確認用 | `python scripts/outreach_gen.py my_leads.csv --tier T0` |
| 5 フォローを計画 | D0/D2/D5のリズム：6日間で3回コンタクト、3回目も無反応なら終了 | `python scripts/followup_plan.py --tier T0 --start 2026-11-24 --csv my_leads.csv` |
| 6 返信が来たら見積 | 原価＋運賃＋利益率 → FOB/CIFの価格帯＋3段階の譲歩ラダー | `python scripts/quote_engine.py --cost 28 --freight 6 --margin 15` |
| 7 音沙汰がなければ催促 | 見積から7日たっても返信がなければ進捗を尋ねる。毅然と、すがらずに | `python scripts/nudge.py --day D7 --scenario quoted` |

ステップ4を終えれば、そのまま送れる初回コンタクトのメールが手元にあります。ステップ5を終えれば、この先6日間、毎日何をすればいいかが分かります。

Pythonがない？ Webサイト [6hn68.github.io/zero-to-trade](https://6hn68.github.io/zero-to-trade/) を開いてください（ローカルにコピーした場合は [`index.html`](index.html) をダブルクリック）。ブラウザで動く4つのツール（リードスコアリング、アウトリーチ、フォローアッププラン、見積）があり、ルールはスクリプトと同じ。画面は12言語に対応しています（右上のメニュー）。サンプルリストを読み込む → スコア化してT0を見つける → 初回コンタクトのメッセージを生成してコピー → `[ ]` のプレースホルダーをご自身の名前、会社、WhatsAppに置き換える → D0/D2/D5のフォローを計画 → 返信が来たら見積。アップロードは一切なし。リストがブラウザの外に出ることはありません。Webサイトの初回コンタクト文面は英語に中国語の参考訳付きです。スペイン語、ポルトガル語、アラビア語の文面が必要なら `outreach_gen.py --lang es/pt/ar` をお使いください。

## これが本当に解決すること

「輸出 始め方」で検索してみてください。出てくるのは、誰か1人の成功談、200本のSEO記事、有料講座の無料お試し部分、そして「すぐ稼げる」と約束するYouTubeのサムネイル。全部読んで、分かった気になる。そして翌朝、通関データのサイトを前にして、最初の入力欄に何を入れればいいのか分からずに固まるのです。

これは情報不足ではありません。情報の形が間違っているのです。細切れにされ、勝者の視点で書かれ、肝心の「手を動かす」直前で終わっている。

たいていのチュートリアルはこう書きます。*「顧客のバックグラウンド調査をしましょう。」* 続いて *「バックグラウンド調査は重要です。」* そしてそれきり。どの項目を、どのサイトで、危険信号とはどういうものか、どこまで調べれば十分なのか。結局何も分かりません。

このリポジトリは正反対のことをします。**1つのタスクを、行動になるまで分解し続ける。**

| チュートリアルの言うこと | このリポジトリの言うこと |
|---|---|
| 「バックグラウンド調査をしよう」 | L1スクリーニング、3つのチェック：サイトは存在するか、会社の登記から何年たっているか、SNSアカウントは生きているか。1つでも引っかかれば、そのリードは見送り。 |
| 「量より質が大事」 | 10件のリードをT0/T1/T2/T3に分類。ティアごとに次の一手と時間の配分が決まっている。 |
| 「フォローアップしよう」 | 1日目、3日目、5日目、7日目。毎回違う切り口で、7日目は「押すか、手放すか」の判断で締める。 |
| 「AIが貿易を変えている」 | 標準ライブラリだけで動く15本のPythonスクリプト（業務スクリプト14本、うち1本は見積エンジン、さらにプライバシーガード1本）。`python scripts/lead_score.py examples/leads_example.csv` を実行すれば、約30秒でティア分けがすべて終わる。 |

情報は同じ。違うのは**粒度**です。差はそれだけ。ここに書かれていることはすべて、1つの問いに耐えなければなりません。今日の午後、何を開いて、何を入力するのか？

というわけで、これは自己啓発ではありません。チェックリストと、15本のスクリプトファイル（業務スクリプト14本＋プライバシーガード1本）です。

## 7つのステージ

国を選ぶところから、口座に入金されるところまで、1本の流れです。ステージごとにドキュメントが1つあり、どのドキュメントも実際に使えるもので締めくくられています。

| ステージ | やること | 成果物 |
|---|---|---|
| **01 市場を選ぶ** | 言語、需要、障壁でスコア化する | 最初の市場1つ＋それを選んだ理由3つ |
| **02 リードを探す** | 4つのルート：通関データ、SNS、検索、展示会 | 1日あたり検証済みリード20件以上 |
| **03 バイヤーを精査する** | L1スクリーニング → L2標準調査 → L3深掘り | A/B/C評価。詐欺業者はふるい落とす |
| **04 コンタクトする** | リードをT0〜T3に分類し、初回コンタクトは3チャネルで | ティア別リスト＋D0/D2/D5のフォローアッププラン（6日間で3回コンタクト） |
| **05 仕様を詰める** | 小さなお願いから。価格は常に最後 | 仕様・数量・仕向港 |
| **06 見積と交渉** | 見積の規律：譲歩するたびに必ず見返りを得る | 見積書＋譲歩ラダー＋トークスクリプト |
| **07 注文を納品する** | 契約、生産、検品、書類、決済、輸送 | 納品までの一連の流れ＋リピート計画 |

ステージのドキュメントは `docs/` にあり、1ステージ1ファイル。すべて同じ6部構成です（[CONTRIBUTING.md](CONTRIBUTING.md) を参照）：**このステージの目的 → ステップごとのやり方 → 合格・不合格の基準 → よくある失敗 → コピペできるテンプレート → このステージで使うAIプロンプト。**

**まったくの初めてですか？** [`docs/00-getting-started.md`](docs/00-getting-started.md) はgitもPythonも知らない前提で書かれており、約10分で動き出せます。急いでいるなら、[`docs/fast-path.md`](docs/fast-path.md) が、ゼロから最初の返信までの7日間プランです。

## 30秒クイックスタート

**Pythonをインストールしたくない？** Webサイトを開いてください：[6hn68.github.io/zero-to-trade](https://6hn68.github.io/zero-to-trade/)。ブラウザで動く4つのツール（リードスコアリング、アウトリーチ、フォローアッププラン、見積）を、12の表示言語で。CSVを貼り付ければT0〜T3のティア分けが出て、続けて初回コンタクト、フォローの日程、見積まで。インストール不要で、ブラウザの外には何も出ません。

スクリプトファイルは15本：業務スクリプト14本（うち1本は見積エンジン）と、プライバシーガードのスクリプト（`check_private_data.py`。コミット前に実在の顧客データがないかスキャンします）。標準ライブラリのみ。Python 3.10以上。

```bash
# 1. Tier your leads. CSV in, T0-T3 out, each tier with its next move.
python scripts/lead_score.py examples/leads_example.csv

# 2. Draft outreach copy for one tier, English and 中文 side by side.
python scripts/outreach_gen.py examples/leads_example.csv --tier T0

# 3. Build the follow-up plan. Three touches, real dates.
python scripts/followup_plan.py --tier T0 --start 2026-10-08 --csv examples/leads_example.csv

# 4. Quote: cost + freight + margin -> FOB/CIF range + a 3-step concession ladder.
python scripts/quote_engine.py --cost 28 --freight 6 --margin 15
```

10件のサンプルリードで最初のコマンドを実行したときの実際の出力です。スクリプトの出力は中国語です。【示例】は「サンプル」を意味する目印にすぎず、最後の列はここでは訳してあります：

| ティア | 会社 | 国 | スコア | 次の一手 |
|---|---|---|---|---|
| T0 | 【示例】海湾轮胎贸易 | サウジアラビア | 95 | 初回コンタクトは今日送る。待たない |
| T0 | 【示例】三角洲轮胎 | サウジアラビア | 88 | 初回コンタクトは今日送る。待たない |
| T1 | 【示例】阿曼蓝海 | オマーン | 77 | 今週中に。文面は今日用意する |
| T1 | 【示例】半岛汽车 | サウジアラビア | 71 | 今週中に。文面は今日用意する |
| T1 | 【示例】尼罗河商贸 | エジプト | 67 | 今週中に。文面は今日用意する |
| T1 | 【示例】迪拜轮毂行 | アラブ首長国連邦 | 65 | 今週中に。文面は今日用意する |
| T1 | 【示例】利雅得汽配 | サウジアラビア | 60 | 今週中に。文面は今日用意する |
| T2 | 【示例】尼日利亚先锋 | ナイジェリア | 50 | コールドプール。1日1回見直す |
| T3 | 【示例】黎凡特供配 | レバノン | 24 | 情報不足。まず連絡先とニーズを調べる |
| T3 | 【示例】利雅得零件店 | サウジアラビア | 17 | 情報不足。まず連絡先とニーズを調べる |

まとめ：**T0:2 / T1:5 / T2:1 / T3:2**。今日連絡する：【示例】海湾轮胎贸易、【示例】三角洲轮胎。今週：【示例】阿曼蓝海、【示例】半岛汽车、【示例】尼罗河商贸、【示例】迪拜轮毂行、【示例】利雅得汽配。今はそっとしておく：【示例】黎凡特供配、【示例】利雅得零件店。

CSVのヘッダー：

```
company,country,product,source,email,phone,years,contact,note
```

必須なのは `company` だけです。ほかはすべて空欄でかまいません。空欄は最低点で計算されます。スコアを最も大きく動かすのは `source` です：`referral` / `trade_show` / `customs` / `linkedin` / `search`。

15本のスクリプトはすべて `--help` に対応しています。`lead_score.py` には `--format json` と `--country` / `--product` のフィルターもあり、スプレッドシートに流し込むこともできます。

スクリプトが決めるのは、機械に決められることだけです。メールアドレスはあるか、Webサイトはあるか、T0の基準を満たすか。そのリードにあなたの午後を使う価値があるかどうかは、ドキュメントと、あなたの頭の中にあります。

## なぜ手法のドキュメントだけでなく、スクリプトなのか

「ビジネスにAIを」系のリポジトリの多くは同じことをしています。方法論をプロンプトに貼り付けて、それを公開する。このリポジトリは逆の順番です。**まず規律、ツールはその次。**

理由はこうです。**プロンプトがうまいことと、貿易がうまいことは別物です。** あなたに足りないのは言い回しではなく、判断の仕方だと私は考えています。だから：

- **ここではルールこそが製品です。** T0には今日メールを送る。T3は3か月引き出しにしまっておく。何の見返りもない譲歩は、交渉ではなくただのプレゼント。こうした判断を、どんなモデルにも代わりにさせてはいけません。
- **量はAIに任せる。** 8件のリードを一度にスクリーニングする、50社分のバックグラウンド調査を3段階で下書きする、7日分のフォロー文面のバリエーションを出す。何時間もかかるのに、判断はほとんど要らない作業です。
- **繰り返せることは、すべてスクリプトにする。** ティア分けが感覚頼みなら、それは基準とは呼べません。だから200行未満・依存ゼロのスクリプトにしました。2人が実行すれば、同じ答えにたどり着きます。

線引きはこうです。**`if/else` で書けるか？ ならスクリプトへ。トレードオフが必要か？ ならドキュメントへ。人間が書いたように聞こえる必要があるか？ なら `prompts/` へ。**

pandasもOpenAI SDKも使っていません。意図的です。初心者が挫折するのは環境構築です。輸出を始めたばかりの人は、顧客探しより `pip install` に多くの時間を取られます。そんなところでつまずかせるのは、あまりにもったいない。

## 貢献する

ここに足りないのはドキュメントではありません。**国ごとの現場の細かい知識**です。中東への最初のタイヤの注文がどう進むかは分かります。でも、エクアドルの建材流通がどう回っているのか、ナイジェリアの税関が実際にどの書類を求めるのかは、まったく分かりません。そこを埋められるのは、現地で売っている人だけです。

参加の方法は3つ。手軽な順に：

1. **何かを直す。** 誤字、古くなった情報、ぼんやりしたルール。issueを立ててください。黙っているより、一文のほうがずっと価値があります。テンプレートで聞くのは3点だけ：どの行で迷ったか、どの数字に出典がないか、どのルールがあなたの業界では通用しないか。
2. **ステージを翻訳する。** スペイン語、アラビア語、ポルトガル語、ロシア語、フランス語、ベトナム語。実際に話せる言語ならなんでも。6部構成はそのままに言語だけを置き換え、用語は [GLOSSARY.md](GLOSSARY.md) に合わせてください。
3. **あなたの国や業界を追加する。** ここが欠けている部分です。「こうすべきだと思うこと」ではなく、「実際にやったこと」を書いてください。項目名、書類名、チャネルの築き方、相手がどう支払うか、そしてなぜ支払いを拒むのか。

コードも歓迎です。ただし絶対ルールが1つ：**Python 3.10以上、標準ライブラリのみ。** 理由は [CONTRIBUTING.md](CONTRIBUTING.md) に書いてあります。

## 開発者の方へ：自由にいじれて、依存はゼロ

14本の業務スクリプト（`lead_score` / `outreach_gen` / `followup_plan` / `quote_engine` / `due_diligence` / `tire_pack` / `landed_cost` / `trade_show` / `nudge` / `anchor_price` / `fast_path` / `market_rules` / `daily_video_list` / `fulfillment_checklist`、それにプライバシーガードの `check_private_data.py`）は、すべて標準ライブラリのみです。`pip install` はありません。フォークして、書き換えて、ご自身のツールに組み込んでください：

- 重みがしっくりこない？ `lead_score.py` の冒頭にある4つの定数（`CONTACT_W / SOURCE_W / SIGNAL_W / MATURITY_W`）を変えてください。上限は変わらず100です。
- 自前の通関データがある？ ヘッダー（`company,country,product,source,email,phone,years,contact,note`）を合わせて読み込ませてください。
- 自分のツールに組み込みたい？ どのスクリプトもきれいにimportできます。`score_lead()`、`render()`、`plan_followups()`、`build_quote()` は辞書やリストを返す純粋関数です。通信なし、ファイル書き込みなし。
- CIはすべてのPRで `py_compile`、テストスイート（Python 3.10–3.13）、プライバシーゲートを実行するので、まずい変更がこっそり紛れ込むことはありません。

> ここでの方針は**賢さより、検証できること。** 私の言葉をうのみにしないでください。`python scripts/lead_score.py examples/leads_example.csv` を実行して、出てきたものを読んでみてください。
