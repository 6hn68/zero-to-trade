# 一笔真实感的第一单（全流程走查）

> ⚠️ **以下公司名、邮箱、价格、对话均为虚构示例**，仅用于演示本项目的 7 个环节怎么串成一笔单。请勿据此联系任何真实企业。所有数字为演示用的占位值。

假设你是轮胎出口新手，主推沙特市场，产品是 TBR（卡客车胎）12.00R20 和 PCR（乘用车胎）。下面用本项目的工具，把「从 0 到第一笔试订单」跑一遍。

---

## 01 选市场 → 锁定沙特

> 对应文档：[01-market-selection.md](01-market-selection.md)

用三维法评估：语言（英语可通）、需求（车队/基建拉动重卡胎）、壁垒（SASO 认证，但可代办）。结论：**首站沙特**，理由三条写进表里。

## 02 找客户 → 20 条里出 1 条 T0

> 对应文档：[02-find-leads.md](02-find-leads.md)

从海关数据 + LinkedIn 攒了 20 条沙特轮胎进口商。其中 `【示例】海湾轮胎贸易` 的来源是 `referral`（同行介绍，可信度最高），且有采购经理直联方式 → 进入分级。

## 03 背调 → L1 过，L2 补

> 对应文档：[03-due-diligence.md](03-due-diligence.md)

- L1：官网存在、成立 18 年、LinkedIn 公司页活跃 → 过。
- L2：用 [`03-due-diligence.md`](03-due-diligence.md) 补了进口记录（年进口约 6 柜）、社媒更新频率。
- 红旗检查：无「刚成立就要大单」「坚持先付样品到私人账户」等信号 → 安全。

## 04 建联 → T0 当天发，LinkedIn 首触

> 对应文档：[04-outreach.md](04-outreach.md)

跑：
```bash
python scripts/lead_score.py examples/leads_example.csv
python scripts/outreach_gen.py examples/leads_example.csv --tier T0
```
得到 T0 名单（`【示例】海湾轮胎贸易` 95 分排第一，共 2 个 T0）。首触走 **LinkedIn**（不先走邮箱，避开垃圾箱），文案带钩子：

> "Hi，看到贵司去年进口了多批 TBR。我们刚交付一批 12.00R20 到利雅得车队，磨耗和生热表现稳定。方便发一下贵司常用规格清单？我按清单给一版 SASO 可落地的 FOB 报价。"

当天收到回复："Send your best price for 12.00R20 and 315/80R22.5."

## 05 聊单 → 小要求先行，价格最后

> 对应文档：[05-negotiation.md](05-negotiation.md)

没立刻报底价。先问清三件套：**规格 / 数量 / 目的港**。客户回：各 1 柜（40HQ），目的港 Dammam。

## 06 报价谈判 → 用报价引擎 + 让步阶梯

> 对应文档：[06-quote.md](06-quote.md)

跑报价引擎：
```bash
python scripts/quote_engine.py --cost 28 --freight 6 --margin 15 --anchor 42
```
得到 FOB 区间 31.18~33.17，CIF 约 39.23，竞品锚价 42 → **我有价格优势**（定位建议自动给出）。

客户压价到 30。按纪律——**让步必须换条件**，而且 30 已低于引擎底线 31.18，**不能裸降**，必须用排他 / 量 / 长约去换。实跑的三档让步阶梯是这样：

| 阶梯 | 报价 FOB | 换回的条件 |
|---|---|---|
| 第 1 步 | 32.50 | 首单 ≥1 个柜（40HQ）锁这个价 |
| 第 2 步 | 31.84 | 升级为年度框架 / 量翻倍以上 |
| 第 3 步（底价） | 31.18 | 签 1–3 年沙特独家 / 排他代理，区域保护换低价 |

客户要的 30 低于底线 31.18，不能直接给；要么守住 31.18 底价、要求他走第 3 步（长约 / 排他），要么用更多量、更长账期去谈，绝不白降。

最终首单：FOB **32.50** × 2 柜，客户确认首单 ≥1 柜 → 走阶梯**第 1 步**，条件达成，不是送钱。

> 提醒：31.18 不是首单价，而是阶梯**第 3 步**的深折扣底价（条件：签 1–3 年排他/独家代理、区域保护换低价）。首单只能走第 1 步 32.50；想拿 31.18 那个底价，得用长约去换，不能一上来就裸给。

## 07 订单交付 → 闭环

> 对应文档：[07-order-delivery.md](07-order-delivery.md)

合同 → 生产（带 SASO 验厂）→ 第三方验货 → 单证（发票/箱单/提单/产地证/SASO）→ 收款（30% 前 T/T + 70% 见提单副本）→ 物流（青岛→Dammam）。交付后建复购计划，进入第二轮 T1 名单推进。

## 这笔单里，工具各干了什么

- `lead_score.py`：把 20 条噪音筛成 T0，避免把时间浪费在垃圾线索。
- `outreach_gen.py`：生成中英对照首触文案，英文发、中文审，不卡语言。
- `followup_plan.py`：T0 按 **D0 / D2 / D5** 三次差异化触达（7 天 3 触达），不靠脑子记。实跑命令：

  ```bash
  python scripts/followup_plan.py --tier T0 --start 2026-10-08
  ```

  （`--start` 填你实际首发当天，格式 `YYYY-MM-DD`）
- `quote_engine.py`：报价有区间、有底线、有锚价定位，谈判不慌；让步阶梯保证每降一分都换回条件。

**核心结论**：这一单不是靠「英语好」或「关系硬」，是靠**顺序对 + 工具把重复劳动吃掉 + 纪律把底线守住**。把这套跑熟，下一单只是复制。
