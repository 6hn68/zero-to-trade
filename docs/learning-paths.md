# 学习路径 Learning Paths：对号入座，别瞎走

> **上下游**：总览见 [README.md](../README.md)｜零基础起手见 [00-getting-started.md](00-getting-started.md)｜7 天最快路径见 [fast-path.md](fast-path.md)。

> **工具对照（15 个脚本文件）**：14 个业务脚本 `lead_score.py`（线索 T0–T3 分级）/`market_rules.py`（目标市场与贸易壁垒规则表，供分级时查）/`outreach_gen.py`（建联文案）/`followup_plan.py`（D0/D2/D5 跟进，6 天 3 次）/`quote_engine.py`（FOB/CIF 报价 + 三档让步阶梯）/`due_diligence.py`（L1/L2/L3 背调 + A/B/C 评级 + 红旗清单）/`tire_pack.py`（轮胎行业包：GCC 认证 + 目的港清关）/`landed_cost.py`（到岸成本：FOB + 运费 + 保险 → CIF，再加关税 + 目的港杂费 → DDP）/`trade_show.py`（展会实战：会后 24 小时跟进计划）/`nudge.py`（催单话术：D3/D7/D14/D30 × 已报价未回/已发样未回/已谈价未定，中英对照）/`anchor_price.py`（竞品锚价：海关数据竞品价区间 + 自家成本 → 进取/中位/保守三档 CIF 锚价 + 5 项复核清单）/`fast_path.py`（七天快路径互动版：每天 `--day N` 看任务、干完 `--done N` 打卡、`--progress` 看进度，与 `docs/fast-path.md` 逐条对齐）/`daily_video_list.py`（每日 5 条视频清单：上午 3 条 + 下午 2 条）/`fulfillment_checklist.py`（履约核对：PI→30% 定金→生产→提单核对，定金/放单/出运三道钱关硬拦），再加 1 个守门脚本 `check_private_data.py`（提交前扫真实客户数据）。全部只用 Python 标准库，零依赖。示例数据只用 `examples/leads_example.csv`（10 条，T0:2/T1:5/T2:1/T3:2），真名单先 `cp` 成自己的 `my_leads.csv` 再填。

## 一句话原理

**不同段位，走不同路。** 新手贪多嚼不烂，高手重复基础是浪费。三条路径，先对号，再出发。

---

## 🌱 新手村（0 基础）

**适合谁**：完全没做过外贸，不知道从哪下手的人。

**走什么**：按顺序走 [01 选市场](01-market-selection.md) → [07 订单交付](07-order-delivery.md)，一步都别跳。

**先走哪个后走哪个**：
1. 先 01 选市场（1 周）：定 1 个首站市场，说出三条理由
2. 再 02 找客户 + 03 背调（2 周）：攒出第一批 50 条合格线索
3. 再 04 建联 + 05 谈判（持续）：发出第一批建联，拿到第一个客户回复
4. 最后 06 报价谈判 + 07 订单交付（有单再学）：先懂纪律，真出单时不慌

**建议走多久**：4-6 周。每天 2 小时。

**毕业标准**：
- [ ] 7 个环节的检查清单全部打勾
- [ ] 发出 ≥30 封建联消息（三线并进算 3 封）
- [ ] 拿到 ≥1 个客户的实质回复（回消息就算，不管成没成单）

**毕业去向**：进阶场。别在新手村刷级，回复率稳定了就往前走。

---

## 🚀 进阶场（已有线索 / 开过单）

**适合谁**：已经跑过 01-07，发出过建联、甚至开过单，但想把量做大的人。

**走什么**：选修 [08](advanced/08-independent-station.md) → [12](advanced/12-risk-compliance.md)，按需选，不必全走。

**先走哪个后走哪个**：
1. 先看短板在哪：缺线索 → 先 09 社媒矩阵；询盘少 → 先 08 独立站/B2B；转化低 → 先 10 展会实战
2. 再补 11 物流支付 + 12 风险合规：单量大了，**不出事比多接单重要**
3. 每个模块跑 2-4 周，验证有效再叠加下一个

**建议走多久**：2-3 个月，一次只攻一个模块。

**毕业标准**：
- [ ] 跑通 **一条**稳定的获客渠道（每天有线索进来，不管是社媒/B2B/展会）
- [ ] 线索量是进场前的 10 倍，或转化率翻倍（二选一达成即可）

**毕业去向**：高手营。渠道稳定了，下一步是"把大鱼打下来"。

---

## 🏆 高手营（稳定出单）

**适合谁**：有稳定订单，想从"做散单"升级到"做大客户、做复购"的人。

**走什么**：[13 大客户开发](advanced/13-key-accounts.md) + 回头打磨 01-07。

**先走哪个后走哪个**：
1. 先 13 大客户开发：选 3-5 家目标，画决策链，90 天进攻
2. 回头打磨 04 建联 + 05 谈判：大客户吃的是"专业度"，把话术升级到拍板人级别
3. 再打磨 06 报价谈判 + 12 合规：大单金额大，**一个坑顶过去一年利润**

**建议走多久**：3-6 个月。ABM 是慢活，90 天一个周期。

**毕业标准**（达成一条即可）：
- [ ] 拿下 1 个年框客户（年度框架协议）
- [ ] 复购率明显提升（老客户主动返单，不用你追）

**毕业去向**：把你的第一单故事讲给新手村的人听——去 README 下面的 Star 区留言，或者给项目提 PR，把你的打法写进来。
