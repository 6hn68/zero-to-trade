# 01·选市场 Market Selection

这一步就一件事：锁定 1 个首站市场（第一站只打一个），再写出选它的三条硬理由。

一句话：新手拼的不是市场多，是市场窄、最快能拿到第一单。

> **上下游**：总览见 [README.md](../README.md) 的「7 环节总览」｜零基础起手见 [00-getting-started.md](00-getting-started.md)｜下一步 [02-find-leads.md](02-find-leads.md) 找客户。

## 一、为什么这一步排在最前

外贸最贵的错误不是选错市场，是同时打五个市场。

同时打五个市场会发生什么？你要写五套开发信模板、查五套认证要求、记五套时差、应付五种付款习惯。做了三个月，每个市场都停在「有几个客户问了价格」，没有一个到成交。

反过来，只打一个市场：一个月能积累 200 条真线索，能搞清这个国家谁说了算、进口需要什么证、经销商从哪进、能接受什么价格。三个月能出第一单。

第一单的意义不只是钱。是它证明你的产品、你的报价、你的合同、你的单证这一整套东西是能跑通的。跑通一次，复制到第二个市场才有底。

所以第一步不是「调研十个国家」，是「砍掉九个」。

## 二、分步操作

**第 1 步：用数据拉候选池，不要凭感觉列（半天）**

照着点就行，不需要先懂外贸：

1. 打开 **UN Comtrade**（联合国商品贸易数据库，免费，注册后可下载）。
2. Commodity（商品）里填你要做的轮胎 HS 子目——乘用车胎、卡客车胎 TBR、工程胎 OTR 各自对应不同子目，**以目标国海关官方最新归类为准**，别照抄网上的编码表。
3. Reporter（报告国）= 你要看的国家；Partner（伙伴国）= World；Trade Flow = **Import**；年份选 **最近 3 年**。
4. 指标选 Primary Value（进口金额，USD）。
5. 按进口金额从高到低排序，**前 20 个国家进候选池**。

拉出来那张表就是候选池，不用你拍脑袋想国家。大多数人脑子里蹦出来的那几个，最后基本都在这张表之外。这很正常，拍脑袋和看数据本来就是两件事。

候选池示意（**仅表示格式，不代表推荐顺序**，真实排序请用上面 5 步自己拉）：
沙特 / 阿联酋 / 伊拉克 / 卡塔尔 / 科威特 / 埃及 / 摩洛哥 / 阿尔及利亚 / 波兰 / 墨西哥 / 巴西 / 印尼 / 越南 / 泰国

> 剔除规则：某国在你做的 HS 子目下连续多年查不到进口记录，直接从候选池删掉，不必进入打分。

**第 2 步：先把数据源和费用弄清楚（30 分钟）**

新手最容易卡住的一点，是「这个数字到底去哪查」。下面这张表按「能不能免费拿到」排好，先照表跑一遍再谈打分。

| 数据源 | 查什么 | 费用 | 取数路径 |
|---|---|---|---|
| UN Comtrade（联合国商品贸易数据库）| 目标国某 HS 子目的进口金额、来源国结构、三年趋势 | 免费（注册后可下载，额度以官网当期公布为准）| 搜索关键词 `UN Comtrade` → 进数据库 → Commodity 填 HS 子目 → Reporter=目标国 → Partner=World → Flow=Import |
| ITC Trade Map（国际贸易中心）| 更友好的进口额 / 来源国 / 增长率视图，适合看「谁在卖给它」 | 基础功能注册免费，深度模块付费（以官网当期公告为准）| 搜索关键词 `ITC Trade Map` → 选国家 → 选产品 HS 子目 |
| 目标国海关 / 国家统计机构官网 | 本国口径的进口数据、税率、认证备案入口 | 多数免费 | 搜索关键词 `[国家名] customs import statistics`、`[国家名] national statistics bureau foreign trade` |
| 目标国轮胎/汽配进口商协会、工商会名录 | 现成的买家名单（这是找客户环节的提前摄入）| 多数免费，少数收会员费 | 搜索关键词 `[国家名] tyre importers association`、`[国家名] chamber of commerce member directory` |
| 展会参展商名录 | 常年参展的活跃买家，兼做经营状况校验 | 多为免费，个别需注册 | 搜索关键词 `[国家名] auto parts expo exhibitor directory`（具体展会名以官网为准）|
| Google Trends | 需求走热的**粗筛方向**，只能当线索，不能当结论 | 免费 | 进入后搜品类英文关键词 → 地区选目标国 → 看多年趋势 |
| 付费海关数据服务（提单/关单数据服务商）| 精确到公司名的进口记录与采购周期 | 付费（个别提供免费样品数据）| 搜索关键词 `customs import data [国家名]`，对比免费额度与报价后再决定 |

说句硬话：这张表里的免费源没跑完之前，别碰付费数据。付费数据唯一不可替代的用途是「精确到公司名」那一层，而那一层发生在 [02-find-leads.md](02-find-leads.md)，不在这一步。

**第 3 步：三维打分（1-2 天）**

每个候选国三项各打 0-5 分。权重记死：语言 1×、需求 1×、壁垒 2×，理由在下面。

- **语言（权重 1×）**：你能否独立读懂这个国家的商界信息。
  - 0-1 分：官方语言你完全不可读，本地 B2B 也不流通英语 → **直接降为第 2 站候选**
  - 3 分：部分行业资料可读，邮件能用英语谈
  - 5 分：商务英语流通，协会/政府名录有英文版
  - 打分依据：用第 2 步的名录，**能不能打开一页你看得懂的成员/展品名单**。
- **需求（权重 1×）**：不看「市场总盘子」，只看能在数据源上复现的三列：
  ① 目标国该 HS 子目最近一年进口金额；② 近三年趋势方向；③ 是否高度依赖进口（来源国结构里本国制造占比是否极低）。**每列都要能在 UN Comtrade 或 Trade Map 上复现**，复现不出来的那一列写 `UNVERIFIED`，不算分。
- **壁垒（权重 2×）**：认证体系、关税、是否强制本地代理、付款条件苛刻程度。
  - 5 分：无强制认证 + 关税低 + 无需本地代理
  - 0 分：强制认证体系复杂 + 高关税 + 必须本地代理 + 只接受苛刻付款条件
  - **为什么算两倍**：壁垒决定的不是「你卖不卖得动」，而是「你发不发得出货、收不收得回钱」。第一单卡死的案例，绝大多数卡在壁垒不在需求。
  - 只写体系名称（如沙特：SASO 认证体系，SABER 为备案平台），**不写条款号、不写税率数字**，一律留「以官方最新公告为准」。

**淘汰线**：任一维度低于 2 分直接出局（尤其「壁垒 0-1 分且需求 ≤2 分」——典型的进得去出不来）。
过关者按加权总分排序，**取前 3**。

**第 4 步：做取舍（30 分钟）——先把这四条判据背下来**

判据 1：**第一单的目标是「跑通全流程一次」，不是「拿下最大的市场」。** 排序第一关键字永远是「最快能出第一单」，不是需求规模。

判据 2：**需求大但认证门槛高 → 放第 2 站。** 门槛高的市场要付出的认证周期、代理成本、送样费用，在第一单验证之前全部是自己先垫的沉没成本。

判据 3：**需求小但能马上出单 → 第一站就是它。**

所以别纠结，先打那个能马上出单的。三条理由：

1. 第一单真正的产出是端到端跑通一次：询盘→报价→合同→单证→收汇→发货→售后。这套流程的难度与市场大小基本无关，小市场跑一次，难度一样是完整的。
2. 门槛高的市场，成本发生在「你还不知道需求是不是真的」之前，是最容易白花的一笔钱。
3. 跑通一次之后，你有真实案例、真实买家反馈、真实单证模板——这三样进大市场时是从 0 到 1 的通行证，没有它们你连大客户的采购系统都进不去。

代价得认：练手市场天花板低，客单价可能也低。所以务必同步做两件事——记下「第 2 站候选」；并在第 1 站验证成功后**提前启动**高门槛市场的认证了解周期，别等想进才动。

判据 4：这一步砍出「第 1 站 1 个 + 第 2 站候选 2 个」，多余的候选不要留在桌面，避免日后分散。

**第 5 步：15 分钟可得性验证（把「我觉得」变成「我找到了」）**

前 3 名逐个做，每个限时 15 分钟，全部用搜索引擎，不靠人脉、不发问卷：

```
检索词 1：[国家名] tyre importers association
检索词 2：[国家名] chamber of commerce member directory
检索词 3：[国家名] auto parts expo exhibitor directory
```

**过关线（三条同时成立才算过）**：

1. 至少打开 **1 个** 能正常浏览的名录/成员页面，页面上能数出 **≥10 个公司名**；
2. 其中 **≥3 家** 带官网链接，或带电话/邮箱字段；
3. 页面语言你读得懂（英文版，或你有可靠翻译手段）。

过不了 → 直接降为第 2 站候选。**这步比打分表更靠谱**：分数是纸面上的，名录是真在那儿的。

**第 6 步：写三条理由（30 分钟）**

每条理由必须写成「事实 + 来源 + 抓取日期 + 待核实」四段式，缺任一段当没写：

```
【维度】事实断言 ｜ 来源：<数据源 + 口径> ｜ 抓取日期：____ ｜ 待核实：____
```

格式示范（**下划线为占位，必须替换成你自己查到的东西，不要照抄**）：

- 【语言】该国协会名录有英文版、商务沟通可用英语 ｜ 来源：`<第 5 步打开的名录页面名>` ｜ 抓取日期：`____` ｜ 待核实：`是否需要当地语言（非英语）沟通材料`
- 【需求】该国 HS `____` 子目近一年进口额在候选池排第 `__`，来源国结构中本国制造占比低（进口依赖）｜ 来源：`UN Comtrade（Reporter=____ / Partner=World / Flow=Import / Year=____）` ｜ 抓取日期：`____` ｜ 待核实：`该子目归类是否与海关官方一致`
- 【渠道】至少 `__` 个公开名录页可采到潜在买家，单页平均 `__` 家公司 ｜ 来源：`<列出页面名>` ｜ 抓取日期：`____` ｜ 待核实：`名录更新时间`

禁止出现这类词：市场广阔、潜力巨大、前景良好、一带一路红利。写了等于没写。

**第 7 步：立最小验证目标 + 先写好退出规则**

目标是数字，不是愿景：

```
30 天内：真线索 __ 条 / 开发信 __ 封 / 回复 __ 个 / 报价机会 __ 个
（参考档【示例】：线索 20 条 / 开发信 100 封 / 回复 5 个 / 报价机会 2 个，按你的客单价与品类上下调）
```

**做不到时按这个顺序归因**（别一上来就否定市场）：

1. **回复数远低于预期** → 大概率是名单或渠道问题，回去 [02-find-leads.md](02-find-leads.md) 换一路（海关→展会→社媒），**先换打法，别急着换市场**。
2. **有人回但没人要报价** → 大概率是产品匹配度或资质问题，回头核一遍第 3 步「壁垒」那一列的四条（认证体系 / 关税 / 是否需本地代理 / 付款条件），并过一遍 [03-due-diligence.md](03-due-diligence.md) 的 L1 三件事。
3. **报价机会有了但都谈崩** → 这是好消息：市场是对的，问题在报价和谈判，走 [05-negotiation.md](05-negotiation.md)。
4. **四条同时为 0** → 才考虑换市场，并从第 1 步重拉候选池。

## 三、判断标准

本环节「做完了」的硬杠杠（照着一条条对，别靠感觉）：

- 市场已砍到 **1 个**（外加 2 个记录在案的第 2 站候选），且有可查证的三维打分支撑（语言/需求/壁垒每项都能给出依据出处，不是拍脑袋）。
- 三维打分已按权重计算（壁垒 2×），任一维度低于 2 分的国家已被淘汰，不是被忽略。
- 每条事实、每个数字都写成「来源 + 口径 + 抓取日期 + 待核实」四段式；残留的 `UNVERIFIED` 项不超过 3 条，且每条都写了去哪核实。
- 前 3 名都做过 15 分钟可得性验证，**过关的三条线（≥10 家公司名 / ≥3 家联系方式 / 页面可读）有截图或链接存证**，不是凭印象通过。
- 三条硬理由均含**具体事实**（数据源名称、检索关键词、集群或名录名称），没有「潜力很大」这类空话。
- 取舍结论符合四个判据：已明确「先打能马上出单的那个」，高门槛大市场已列在第 2 站，不是被含糊地留着。
- 30 天最小验证目标已**量化**（线索数 / 发件数 / 回复数 / 报价机会数），且已写好做不到时的归因顺序。
- 已记录 ≥3 个公开展会 / 协会 / 商会名录名称及其检索到的页面，作为 [02-find-leads.md](02-find-leads.md) 的直接输入。

> 一句话自检：把你的结论交给一个不了解这个国家的人看，他能不能按你写的东西**复现**出来？复现不出来，就等于还没做完。

## 四、AI 提示词

**提示词 1：市场三维打分**

```
You are an export market analyst specialized in B2B tire sales (China-based exporter).
Task: Score the following candidate markets for a NEW exporter with limited budget and no
existing relationships: {paste your country list}.

Score each country 0-5 on three dimensions:
1. Language accessibility (English usable in B2B trade? official/industry data readable?)
2. Demand size (import volume for tires HS40 subheadings; growth trend; import dependence)
3. Entry barrier (certification scheme, tariff rate, agent requirement, payment terms difficulty)

CRITICAL RULES:
- Do NOT invent numbers. If you do not have a verified figure, write "UNVERIFIED - needs Comtrade
  or official customs check".
- For certification requirements, state the scheme NAME (e.g. SASO/SABER; Saudi: SASO is the certification scheme, SABER is the platform) but never fabricate
  article numbers or clause text. Add: "confirm on the official portal".
- For tariffs, write "check current tariff schedule of the destination customs authority".

Output format: a markdown table with columns Country | Language | Demand | Barrier | Total |
One-line reason | Verification needed. Then a short "Top 3 recommendation" section with
3 bullet points each, max 40 words.
```

白话版：让 AI 当出口市场分析师，但死命令它不许编数字——不确定的一律标 UNVERIFIED。目的是让 AI 先搭骨架、把该核实的地方标出来，你再去查官方源核实。

**AI 给完之后，你必须做的人工核实闭环（3 步，每份输出都做）**：

1. **挑出所有 UNVERIFIED 行**，按提示词 1 输出里 `Verification needed` 那一列，回到 UN Comtrade / ITC Trade Map 用同一口径（Reporter / HS 子目 / 年份）复算一遍。
2. **核实认证与备案入口**：认证那一列只保留体系名称（例如沙特 SASO 认证体系 + SABER 备案平台），然后去该体系官方门户确认当前适用范围与所需文件清单，把官方页面名称记在备注里，不写条款号、不猜税率。
3. **把核实结果回填**：能核实的写「来源 + 抓取日期」，核不实的**删掉那一整行理由**，不要写"约""大概"。一个二手结论留在文档里，后面每一步决策都会被它污染。

**提示词 2：目标市场买家画像**

```
Act as a senior sales director for a Chinese tire manufacturer (exporting to {country}).
Based on the top 3 buyer segments below, produce a buyer profile card for EACH segment.

Segments: (1) independent tire importers & distributors, (2) tire dealer chains / retail groups,
(3) fleet & mining OTR tire operators, (4) tire distributors serving garages.

For each segment output EXACTLY these fields:
- Who they are (role in the import chain, who signs, who influences)
- Typical order reality: container type (20GP/40HQ), rough loaded quantity range,
  and 2-3 common specs (e.g. 12.00R20, 315/80R22.5, 7.00R16) — present as ranges/plausible
  examples, NOT as market data
- What they care about most: price / payment terms / certification / warranty claim handling /
  delivery reliability (rank top 3)
- Where they are findable: named PUBLIC sources only (customs data platforms, LinkedIn,
  trade fair exhibitor lists, chamber of commerce directories)
- The ONE question that makes them reply to a cold email
- Red flags that mean "not a real buyer" (e.g. asks for free sample of expensive goods,
  refuses video call, email domain mismatch)

Format as a markdown card per segment. Max 120 words per field. No marketing language.
```

人话：这段是把「一个大市场」拆成四类不同买家。不同买家在意的东西完全不一样。经销商看价差，矿山运营商看耐磨和理赔。把它们分开，你的开发信才不用一份模板打天下。

**提示词 3：进入路径体检**

```
You are a trade compliance advisor. I am a Chinese exporter of tires planning to sell into
{country}. List the practical ENTRY CHECKLIST I must complete before the first shipment.

Cover, in order:
1. Product certification schemes that apply (name them; do NOT quote clause numbers)
2. Labeling / marking requirements (language, sidewall, invoice)
3. Customs HS classification note (tire categories: passenger, truck/bus, TBR, OTR, inner tube)
4. Typical importer-of-record arrangements and whether a local agent is expected
5. Payment terms that first-time buyers usually get (T/T, L/C at sight, CAD, O/A risk)
6. 3 things I should confirm with a local customs broker BEFORE sending samples

Rules: every item must end with a "VERIFY AT:" line naming the official authority or portal
to check. If uncertain, say so explicitly. Never invent duty rates or document numbers.
```

说白了：这段专门防「样品发出去了才发现认证过不了」这一出。核心是每个条目都要求 AI 写出「去哪核实」，把 AI 当线索生成器，不当答案机。

## 五、检查清单

- [ ] 候选池是用 UN Comtrade 按 HS 子目拉出来的（≥10 个国家），不是凭印象列的
- [ ] 打分前已跑完至少 3 个免费数据源（UN Comtrade / Trade Map / 目标国官方或协会名录），且没有在免费源用尽之前购买付费数据
- [ ] 每个候选国完成三维打分：**语言 1× / 需求 1× / 壁垒 2×**，且每一列的依据都能在数据源里复现（找不到依据的列写 UNVERIFIED，不算分）
- [ ] 任一维度 < 2 分的国家已被淘汰出候选池，而不是「留着看看」
- [ ] 前 3 名均完成 15 分钟可得性验证，满足 ≥10 家公司名 / ≥3 家联系方式 / 页面可读三条线
- [ ] 取舍结论符合四条判据，**第一站是「能最快出单」的那个**；「需求大但门槛高」的已明确列为第 2 站
- [ ] 三条硬理由全部写成「事实 + 来源 + 口径 + 抓取日期 + 待核实」四段式，没有空位、没有「潜力很大」这类空话
- [ ] 所有引用的进口额、趋势、税率都已标注数据来源与抓取时间；`UNVERIFIED` 项已去官方源核实，或被整条删掉
- [ ] 认证要求只写了体系名称（如沙特 SASO 认证体系 + SABER 备案平台），并注明「以官方最新公告为准」，没有编条款号或税率数字
- [ ] 最终只保留 1 个首站市场，另外 2 个作为「第 2 站候选」记录在案，且已写下何时重新评估
- [ ] 30 天最小验证目标已写成数字（线索数/发件数/回复数/报价机会数），并已写好 4 条归因顺序
- [ ] 目标市场的 ≥3 个公开名录（展会/协会/商会）名称与页面已记下来，可直接带进 [02-find-leads.md](02-find-leads.md)

## 六、新手常见坑

**坑 1：一上来就选美国 / 欧盟（新手第一高频错误）**

如果你现在正准备把美国或欧盟写成第一站，先看这段，再决定要不要继续：

- 现象：宏观数据最大最好查、身边人都在谈、看起来最「正规」，于是第一站就锁定美国或欧盟。
- 它对新人的三处致命性：
  1. **认证前置**：两地都有成熟且更新频繁的轮胎准入体系（美国侧 DOT 等联邦要求、欧盟侧 E 标记与轮胎标签类要求），体系名称可以查，**具体适用范围和清单必须去官方门户核**；这类合规动作周期长、需本地责任主体参与。
  2. **买家早就排好队了**：大买家已有稳定供应商名录，新人拿到的往往是最难谈的那批；你面对的是「换供应商成本」，不是「价格高低」。
  3. **责任重**：产品责任、召回与索赔处理在当地是硬约束，第一单就想扛这套，容易赔进去的比赚的多。
- 正确做法：把美国/欧盟（以及任何「国内生产总值大 + 认证体系复杂」的市场）**写进第 2 站候选**，然后从第 4 步的判据出发，先选一个 30 天内能摸到 20 个真线索的市场。
- **不是不要做，是要排序**：放到你已经有第一单、有真实案例和单证模板之后再做，成功率差一个量级。
- 记住排序：能证明自己交付得起 > 市场规模。

（同一个坑还有一个变体：拿巴西、印度这类关税与本地规则复杂的市场当第一站，问题性质完全一样。）

**坑 2：三维打分打完就算选完了**
- 现象：表格做完，标了一个第一名，然后就去写开发信了。
- 原因：打分表是纸面判断，没经过任何真实接触。
- 正确做法：**第 5 步的 15 分钟可得性验证是强制步骤**，不是选做。前 3 名各花 15 分钟去名录里真的数出 10 家公司的名字和 3 个联系方式。找不找得到，比分数准——找不到的国家，分数再高也是纸面上的市场。

**坑 3：拿三年前的报告当现状**
- 现象：引用一篇 2021 年的文章说某国需求暴涨，结论直接写进方案。
- 原因：搜索引擎排前面的还是老文章，新数据反而不显眼。
- 正确做法：所有数字标注来源 + 发布时间，超过一年的数据必须重新核实。海关数据、UN Comtrade、目标国官方统计机构是硬数字来源，行业文章只做线索。

**坑 4：认证要求「听说」一下就过**
- 现象：听说中东要认证，就没再往下查，反正还没发货。
- 原因：认证是「发货前必须做完」的事，不做不影响当下出单，所以一直往后拖。
- 正确做法：选完市场的第二天就动手查目标国的认证体系和备案入口，把「需要哪些文件、找谁办、大概周期」写成三行字贴在桌面上。

**坑 5：把「我朋友在那儿」当理由**
- 现象：因为认识一个当地客户，就决定主攻这个国家。
- 原因：朋友能开门，但开不了整扇门，市场容量和竞争状况还是空白。
- 正确做法：朋友这条线单独保留为「暖启动通道」，市场选择仍然按三维打分走。两条腿走路，别把一条腿当全部。

**坑 6：免费数据源还没跑完就去买付费数据**
- 现象：一听说有能查到公司名的海关数据平台，立刻付款，用了一个月才发现免费源已经能回答 80% 的问题。
- 原因：把「更多数据」当成「更好决策」，忽略了这一步真正需要的只是排序。
- 正确做法：第 2 步那张免费源表格全部跑通后再评估付费。**付费数据是哪个环节的弹药？[02-find-leads.md](02-find-leads.md) 的，不是选市场这一步的。**

**坑 7：为了选错的市场反复换打法（归因错误）**
- 现象：第一周没回复就换开发信模板，第二周还没回复就换渠道，第三周又换关键词——三个月都在换姿势，从没回头看市场本身。
- 原因：把「市场选错」和「打法不对」混为一谈，于是永远在表层修补。
- 正确做法：按第 7 步的 4 条归因顺序走。**有人回复但谈不拢 = 市场是对的，别动市场**；四条同时为 0 才重拉候选池。归因顺序写下来就是为了防手忙脚乱。

- `pulled_from` 固定写数据源名：`UN Comtrade` / `ITC Trade Map` / `<目标国海关官网名>`。

## 八、下一环节

市场定下来了，接下来要在这个市场里挖出具体的人。下一步是 **找客户** —— 把「这个国家有轮胎进口」变成「这 20 个公司名和联系方式」。

下一步：[`02-find-leads.md`](02-find-leads.md) 用四路并行（海关数据 40% / 搜索 30% / LinkedIn 20% / 展会 10%）挖客户，你在模板 C 里记下的 3 个名录页面直接当第一批采集源。

**带过去的东西**（别在这一步丢掉）：

| 本环节产出 | 在下一环节怎么用 |
|---|---|
| 模板 C 的 3 个可浏览名录页 | 直接作为第一天采集的起点，省掉重新找入口的时间 |
| HS 子目与 UN Comtrade 口径 | [02-find-leads.md](02-find-leads.md) 第 2 步拉目标国进口记录时复用，不用重定口径 |
| 壁垒那一列的认证体系名称 | 判断买家是否具备进口资质（[03-due-diligence.md](03-due-diligence.md) L1）时会用到 |
| 第 2 站候选名单 | 找客户期间**不许**同时开；记在案，等第 1 站验证结束再动 |

**回退**：如果模板 D 的四段式里 `待核实` 超过 3 条且一时查不到，不要卡在这一步——带着 `UNVERIFIED` 标记继续往 [02-find-leads.md](02-find-leads.md) 走，用真实买家反馈回来补数据，往往比坐在电脑前查更快。
