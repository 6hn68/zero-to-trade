# 竞品锚价：报价之前，先看竞品卖多少钱

> **这是什么**：报价之前先锚价。海关数据里竞品卖多少钱，你就该报多少钱——不是拍脑袋，也不是拿成本加个百分比就往外报。这个脚本拿海关数据里的竞品价区间（最低/最高/中位），对照自家成本，算出三档建议报价——进取价/中位价/保守价，每档写清毛利空间和适用场景。报出去之前，再过一遍 5 项复核清单（成本、运费、汇率、付款条件、有效期），有一项没打勾就标出来提醒你。
>
> **先说清楚**：竞品价是海关数据里的**成交价区间**，不是某一家对手的报价单——区间里可能混了不同规格、不同认证的货，区间太宽（最高价比最低价高 50% 以上）脚本会直接提醒你先确认。锚价只解决"报多少钱"这一个问题，报不报得成还得看 `quote_engine.py` 的让步阶梯和 `nudge.py` 的跟进。口径与 `quote_engine.py` / `landed_cost.py` 逐字同一套：成本基数 = FOB 成本 × (1 + 不可预见费 3%)，保本 CIF = (成本基数 + 运费) ÷ (1 − 1.10 × 保险费率)，三档锚价是 CIF 价，同一组数字三边算出的 CIF 必须一致（测试里有交叉核对）。

## 用法

```bash
# 最简：竞品价区间 + 自家成本 + 运费 + 关税（【示例】价格全部虚构）
python scripts/anchor_price.py --comp-low 38 --comp-high 46 --comp-median 42 --cost 28 --freight 6 --duty 10

# 低于成本：竞品中位价比自家保本价还低，直接警告，别硬接
python scripts/anchor_price.py --comp-low 30 --comp-high 36 --comp-median 33 --cost 28 --freight 6

# 客户视图：只给三档报价与适用场景，成本、毛利、复核清单全砍掉
python scripts/anchor_price.py --comp-low 38 --comp-high 46 --comp-median 42 --cost 28 --freight 6 --duty 10 --audience client

# 中位价没给：按（最低 + 最高）/ 2 估算，并注明是估算值
python scripts/anchor_price.py --comp-low 44 --comp-high 56 --cost 30 --freight 5

# 复核清单一次勾完：5 项全打勾，警告就消失
python scripts/anchor_price.py --comp-low 38 --comp-high 46 --comp-median 42 --cost 28 --freight 6 --duty 10 --verified cost,freight,fx,payment,validity

# JSON 输出，方便贴进表格或交给 AI 复核
python scripts/anchor_price.py --comp-low 38 --comp-high 46 --comp-median 42 --cost 28 --freight 6 --duty 10 --format json

# 存成文件
python scripts/anchor_price.py --comp-low 38 --comp-high 46 --comp-median 42 --cost 28 --freight 6 --duty 10 --out anchor_internal.txt
```

`--help` 里有 5 个亲手跑过的真实例子。所有金额默认 USD/条，`--currency` / `--unit` 可改。

## 算法（跟 quote_engine.py / landed_cost.py 同一条公式）

| 步骤 | 公式 | 说明 |
|---|---|---|
| 成本基数 | `FOB 成本 × (1 + 不可预见费 3%)` | 与 `quote_engine.py` 相同，不可预见费默认 3% |
| 保本 CIF | `(成本基数 + 运费) ÷ (1 − 1.10 × 保险费率)` | 保险按 CIF 货值的 110% 投保；低于这个价，每条都亏 |
| 进取价 | `中位价 × 97%` | 抢单档，毛利最薄 |
| 中位价 | `中位价` | 默认档，跟市场齐平 |
| 保守价 | `中位价 × 103%` | 保利润档，毛利最厚 |
| 每档 FOB 对等价 | `该档 CIF × (1 − 1.10 × 保险费率) − 运费` | 把 CIF 公式倒推回去，方便拿去跟 `quote_engine.py` 对数 |
| 每档毛利 | `该档 CIF − 保本 CIF` | 毛利按未四舍五入的原值算，再四舍五入到分 |
| 每档毛利率 | `毛利 ÷ 该档 CIF` | 按售价算，与 `landed_cost.py` 的利润率同口径 |
| 每档隐含加成 | `FOB 对等价 ÷ 成本基数 − 1` | 换算成 `quote_engine.py` 的 `--margin` 口径，拿这个数去跑报价引擎，对得上 |
| DDP 价 | `CIF 价 × (1 + 关税税率)` | 关税按 CIF 计，与 `landed_cost.py` 相同；没给 `--duty` 就不另算，DDP 价等于 CIF 价 |

## 锚价指南：什么时候用哪一档

| 档 | 什么时候用 | 什么时候别用 |
|---|---|---|
| 进取价（中位 × 97%） | 抢单、进新市场、首单破冰；量大、长期合作、或客户明确拿着别家报价在比价 | 量小、一次性单、客户不比价——白白让 3% |
| 中位价（= 中位价） | 默认档：多数情况先报这档。跟市场齐平，不拼低价也不高挂 | 你的品牌、认证或交期明显比竞品强——报中位等于把优势白送了 |
| 保守价（中位 × 103%） | 品牌、认证或交期有优势；小单、定制单、或客户不比价 | 客户明确比价、或竞品区间本身就偏低——高挂 3% 等于把单推出去 |

**低于成本怎么办**：三档里只要有一档低于保本 CIF，脚本就标出来并警告"低于成本，别接单或先谈量换价"。三档全低于成本（中位价本身就比保本价低），别硬接，别想着"先接单再说"——先做下面三件事，按顺序：

1. 谈量换价：量翻倍、签长约，拿量去跟工厂谈更低的成本，成本下来了再报。
2. 换便宜规格：换个成本低的规格或型号，重新锚一次价。
3. 放弃这单：成本谈不下来、规格换不了，这单不做——亏本单做得越多，死得越快。

**没有中位价怎么办**：海关数据只给了最低价和最高价，没给中位价时，脚本按（最低 + 最高）/ 2 估算，并在输出里注明"这是估算值"。估算的中位价只能先用来框范围，报出去之前先跟海关数据核对真实中位价——区间不对称（比如最低 38、最高 46，但真实中位是 39）时，估算值会把你带偏。

## 客户视图长什么样

同一组数字加 `--audience client`：只剩三档报价（CIF / DDP）与适用场景，成本、毛利、FOB 对等价、隐含加成、保本价、复核清单、内部提醒一行都不出现——JSON 版连 `meta.inputs` 一起删（跟 `quote_engine.py` / `landed_cost.py` 同一个脱敏口径）。发客户永远加 `--audience client`。

## 跟其他脚本的配合

报价前先锚价，再报：先用 `anchor_price.py` 定三档（竞品价区间 + 自家成本 → 进取/中位/保守），再用 `quote_engine.py` 按中位价那档的隐含加成出正式报价单（FOB/CIF + 三档让步阶梯），最后用 `landed_cost.py` 算到岸全成本（FOB + 运费 + 保险 → CIF，再加关税 + 目的港杂费 → DDP）。顺序别反：锚价是报价的输入，报价是到岸成本的输入。DDP 报出去之前，先看一眼 `tire_pack.py` 的目的港清关单证——税率和单证都对上，DDP 才站得住。

## 常见报错

| 报错 | 原因 |
|---|---|
| `✗ 竞品最低价高于最高价` | `--comp-low` 与 `--comp-high` 填反了 |
| `✗ 竞品中位价不在最低价与最高价之间` | `--comp-median` 抄错行了，先核对海关数据 |
| `✗ 自家 FOB 成本必须 > 0` | 漏了 `--cost` 或填了 0/负数 |
| `✗ 海运费不能为负` | `--freight` 填了负数 |
| `✗ 关税税率不能为负` / `大得离谱（上限 1000%）` | `--duty` 填错单位：这里填百分比，10 表示 10% |
| `✗ 保险费率 30.000% 异常(>5%)` | `--insurance` 填了 30：这里填百分比数值，0.3 表示 0.3%，不是 30 |
| `✗ 复核项只能是 cost/运费……` | `--verified` 里有不在 5 项里的词：cost,freight,fx,payment,validity（或中文：成本,运费,汇率,付款条件,有效期） |
| `✗ --validity 报价有效期必须是 1–365 天` | `--validity` 填了 0、负数或超过 365 |
| `usage: ... the following arguments are required: --comp-low` | 缺必填参数，`--comp-low` / `--comp-high` / `--cost` 三个必填 |
