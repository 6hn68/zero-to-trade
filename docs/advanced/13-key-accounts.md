# 13·大客户开发 Key Accounts

> **上下游**：总览见 [README.md](../../README.md) 的「7 环节总览」｜上一步 [12·风险与合规](12-risk-compliance.md)｜这是进阶模块最后一篇。

## 本环节目标

从"做散单"升级到"做大客户"。输出：1 份 ABM 目标客户作战图 + 决策链切入计划。

## 一句话原理

**ABM（Account-Based Marketing，目标客户营销）：别广撒网等鱼，选一条大鱼，调动所有资源打它。** 散单靠运气，大客户靠作战。一个年框大客户，顶 50 个散单。

## 分步操作

### 1. 选目标：什么样的算"大客户"

- 年采购量是你平均订单 10 倍以上的
- 决策链可触达（LinkedIn 能找到人不等于能触达，要有人能引荐或能写出打动人的首触）
- 行业头部或区域龙头（一家拿下，半个市场跟你走）
- **一次只打 3-5 家**——多了就是散网，少了撞运气

### 2. 决策链切入：从使用者打到拍板人

大公司的采购不是一个人，是一条链：使用者 → 采购员 → 部门经理 → 拍板人（总监/老板）。

- **从使用者切入**：工程师、现场负责人最懂痛点，也最愿意说话。问"现在用的 XX 有什么不爽"，拿到一手情报。
- **用情报打采购员**："你们现场反馈 XX 问题，我们的新品正好解决了这个"——你比别的供应商多一张牌。
- **最后见拍板人**：只谈三件事——省多少钱、省多少事、风险谁担。拍板人不关心参数，关心结果。

### 3. 样品策略：样品是敲门砖，不是成本

- 小样品：免费寄，量少、快——让对方"先看到东西"
- 大样品/打样：到付或收样品费（下单抵扣）——过滤白嫖
- **样品跟进 3 步**：寄出当天通知单号 → 到货后 3 天问"测试了吗" → 1 周后问"报告出来了吗，需要我配合什么"——样品寄出去不管=钱扔水里

### 4. 长期关系维护节奏（拿下之后才是开始）

| 频率 | 动作 |
|---|---|
| 每月 | 1 条有用的市场情报/行业新闻（不是问候） |
| 每季 | 1 次新品/方案推荐（跟他的业务相关） |
| 每年 | 1 次线下拜访或展会面谈 |
| 节日 | 当地节日问候（记他的节日，不是你的） |

**核心**：每次联系都带"新东西"，别"在吗""最近怎么样"。你的消息要值得他点开。

## 行业例子（全部虚构）

- **机械**：刘工锁定巴西 3 家大农场主。从农场机械师（使用者）切入，聊出"现有脱粒机雨季故障率高"的痛点，带着"防潮改进款"方案打到农场主（拍板人），一单顶过去半年。
- **灯具**：陈老板打尼日利亚一家连锁建材商。先给门店工程师寄免费小样，对方测试说"比现有货亮"，拿着测试反馈去找采购总监谈年框——样品开路，数据说话。
- **服装**：林姐盯沙特一单政府工装招标。从招标文件反推决策链，先搞定技术标（面料参数），再搞定商务标（价格+交期），两条线并进，中标。
- **家居**：周总维护德国一家连锁商超 3 年。每季度发一封"欧洲户外家具趋势简报"，对方新品开发会直接叫他参加——从供应商变成"编外顾问"，订单自然来。

## 新手常见坑（高手也常犯）

- **坑 1：一上来就找老板。** 没有内部情报，老板 3 分钟送客。先使用者，后拍板人，这是纪律。
- **坑 2：样品寄出就不管。** 样品的价值不在"寄"，在"跟"。不跟进的样品=捐赠。
- **坑 3：拿下就躺平。** 大客户是"养"出来的，不是"签"出来的。签完不维护，第二年就换供应商。
- **坑 4：同时打 20 家"大客户"。** ABM 的精髓是集中火力。20 家=每家都不用心=全丢。
