# 5 天从零到第一封客户回复（新手最快路径）

> 你发 200 封开发信 0 回复，不是英语差，是顺序错了。这条路径把「选市场 → 找客户 → 背调 → 建联 → 跟进」压成 5 天能跑完的最小动作，每天 1–2 小时，目标只有一个：**收到第一封真人回复**。

判断标准先说清楚：本项目的纪律是「T0 今天就必须发，T3 丢进池子三个月不碰」。新手最容易犯的错是把时间花在写完美邮件上，而不是先把客户筛对。这条路径反过来——**先筛对，再发，再跟**。

---

## Day 0 · 准备（30 分钟）

- **目标**：环境就绪，知道每天打开哪个文件。
- **动作**：
  1. 装 Python 3.8+（不会装看 [`00-getting-started.md`](00-getting-started.md)）。
  2. 不想装？直接双击 [`index.html`](../index.html) 体验分级 Demo，零安装。
  3. 读 [`README.md`](../README.md) 的「7 环节总览」表一遍，建立全局感。
- **验收**：能跑 `python scripts/lead_score.py examples/leads_example.csv` 看到 T0-T3 分级。

---

## Day 1 · 选市场 + 找 20 条线索

- **目标**：定 1 个首站市场，攒 ≥20 条真线索（有公司名 + 国家 + 至少一种联系方式）。
- **动作**：
  1. 按 [`01-market-selection.md`](01-market-selection.md) 的三维法（语言 / 需求 / 壁垒）定首站，写 3 条理由。
  2. 按 [`02-find-leads.md`](02-find-leads.md) 四路（海关数据 / 社媒 / 搜索 / 展会）每天找 ≥20 条。
  3. 把线索整理成 CSV，表头：`company,country,product,source,email,phone,years,contact,note`。
     - `source` 填 `referral` / `trade_show` / `customs` / `linkedin` / `search` 之一（这项对分数影响最大）。
- **验收**：一份 ≥20 行的 CSV，每行至少一个邮箱或电话。

---

## Day 2 · 背调 + 自动分级

- **目标**：用 L1 筛查砍掉骗子/皮包，再用脚本把剩余线索分成 T0-T3。
- **动作**：
  1. 按 [`03-due-diligence.md`](03-due-diligence.md) 的 L1 三件事（官网存在？成立年份？社媒活跃？）逐条过，任一不过直接淘汰。
  2. 跑 `python scripts/lead_score.py 你的.csv`，看分级。
  3. 重点圈出 **T0**（今天必须发）和 **T1**（本周）。
- **验收**：分级结果里 T0/T1 名单清晰，「先回谁」明确。

---

## Day 3 · 建联文案 + 首发（LinkedIn / WA 优先）

- **目标**：给 T0 发出第一条消息，并且**不走邮箱首触**（邮箱进垃圾箱概率高，先放后面）。
- **动作**：
  1. 跑 `python scripts/outreach_gen.py 你的.csv --tier T0` 生成中英对照文案（英文发，中文给你审）。
  2. 按 [`04-outreach.md`](04-outreach.md) 的渠道顺序：**LinkedIn / WhatsApp 先发，邮箱作为跟进**。
  3. 每条消息带一个具体钩子（参考你挖到的信号：刚参展 / 在招采购 / 发了 RFQ），不要群发同一句。
- **验收**：T0 全部发出，且每条都带「为什么是你」的具体理由，不是模板填空。

---

## Day 4 · 跟进（第 1 / 3 天触达）

- **目标**：对 Day 3 没回的，按节奏补第 2 次触达，角度换一个。
- **动作**：
  1. 跑 `python scripts/followup_plan.py --tier T0 --start 今天 --csv 你的.csv` 生成 7 天 3 触达计划。
  2. 执行第 1 天（首发后第 1 天）和第 3 天的触达，每次话术不同（补充一个价值点 / 一个案例 / 一个提问）。
  3. 把回复（哪怕「not interested」）记下来，回复本身就是信号。
- **验收**：跟进计划表生成，且至少完成 2 次差异化的后续触达。

---

## Day 5 · 复盘 + 放大

- **目标**：把 5 天的数据变成可复制的动作，并决定下周放大哪一类客户。
- **动作**：
  1. 数一下：发出多少、回复多少、回复率多少（哪怕只有 1 封也是正样本）。
  2. 看哪类 `source` / 哪国 / 哪产品回复最好，下周把精力压到这一类（这就是「精度与规模不矛盾」）。
  3. 把跑通的 CSV 和复盘记进自己的表，循环 Day 1-5，每周一轮。
- **验收**：有一个数字化的「发出 / 回复 / 回复率」，并锁定下一周的主攻客户类型。

---

## 为什么这条路径能出回复

传统做法把「写邮件」当核心，结果 200 封 0 回复。这条路径把核心换成三件事：

1. **顺序**：先筛对（T0）再发，不把好钢用在垃圾线索上。
2. **通道**：LinkedIn / WA 首触，邮箱跟进，绕开垃圾箱。
3. **信号**：每条都带具体钩子，不是「希望和您合作」。

做到这三点，第一封回复不是运气，是数学。
