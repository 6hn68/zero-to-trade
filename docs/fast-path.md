# 7 天从零到第一封客户回复（给新手的野路子）

> 你照着网上教程发 200 封开发信，0 回复，第一反应多半是「我英语不行」。其实多半不是英语的事，是顺序反了。这条路把选市场、找客户、背调、建联、跟进几步，压成 7 天能跑完的最小动作——每天也就 1 到 2 小时，地铁上都能挤出来。

先把丑话说前头——这玩意儿保什么、不保什么：

- ✅ **保**：到第 7 天结束，你真刀真枪触达过三次——公司是真的，人也是真的，三封信都发出去了，日期全排进日历了。
- ❌ **不保**：能不能收到回复，更别说成单。回复这事看产品、看时机、还得看运气——有人第 2 天就回，有人第 8 周才冒泡。这条路只负责把动作做对，不负责给你打包票。
- ⚠️ 谁跟你说「照做必出单」，直接当他忽悠。外贸没有必出单这回事，只有把概率往上拱一点点的动作。
- ⚠️ 谁跟你说「照做必出单」，直接当他忽悠。外贸没有必出单这回事，只有把概率往上拱一点点的动作。

记一条纪律：T0 今天就得发，T3 丢进池子三个月别碰。新手最爱犯的毛病是把时间全砸在写一封「完美邮件」上，而不是先把人筛对。这条路反过来走——先筛对的，再发，再跟。

> **开跑前 10 秒**：下面所有命令，都在**仓库根目录**里敲——就是你能同时看到 `scripts/` 和 `examples/` 的那个文件夹。Windows 上要是 `python` 报错说「不是内部或外部命令」，把命令里的 `python` 换成 `python3`，或者回去翻 [`00-getting-started.md`](00-getting-started.md)。

## Day 0 · 准备（30–40 分钟）

- **今天做什么**：
  1. 装个 Python 3.8 以上（不会装去看 [`00-getting-started.md`](00-getting-started.md)）。嫌麻烦？直接双击 [`index.html`](../index.html)，分级 Demo 零安装就能玩。
  2. 把 [`README.md`](../README.md) 里那张「7 环节总览」扫一遍，混个眼熟就行——知道有哪 7 步，不用背。
  3. 注册个 LinkedIn，再准备一个能正常收发消息的 WhatsApp（建议用 Business 版，工作和生活好隔开）。
- **怎么算过关（二选一，做到一条就成）**：
  - 装了 Python 的：跑 `python scripts/lead_score.py examples/leads_example.csv`，屏幕蹦出一张分级表，最底下那行 `汇总: T0:x / T1:x / T2:x / T3:x`；
  - 走零安装路线的：双击 `index.html`，把示例 CSV 粘进去点「开始分级」，看到一样的 T0–T3 结果。
- **两条都够不着怎么办**：这一步别磨超过 40 分钟，跳过脚本照样能跑完——T0/T1/T2/T3 啥意思，[`index.html`](../index.html) 页面底下就写着，手画表格也能分。
- **LinkedIn 当天没搞定也别停**：新号得养几天才像真人，Day 3 首触先用 WhatsApp 或邮箱顶上，LinkedIn 留着当第二次触达的渠道。

## Day 1 · 定 1 个市场 + 找 10–15 条线索（≤2 小时）

- **今天做什么**：
  1. **定一个首站（20 分钟，一个就够）**：照着 [`01-market-selection.md`](01-market-selection.md) 那套三维法（语言 / 需求 / 壁垒）挑 1 个国家，写 3 条理由。**实在选不出就先选英语市场，或者你能看懂文字的市场**——市场选错下周还能换，卡在这不动才是真亏。
  2. **找线索（60–90 分钟）**：按 [`02-find-leads.md`](02-find-leads.md) 的四路（海关数据 / 社媒 / 搜索 / 展会）去找，**今天只要 10–15 条**，别贪多。
     - **说点实在的**：零基础第一天就想凑 20 条「带邮箱」的线索，基本是做梦。**先攒公司名 + 国家 + 来源就成，邮箱电话 Day 2 再补**——补联系方式比找公司容易太多了。
     - **省钱提醒**：海关数据大多要钱，新手先用**免费三路**起步就够——展会官方名录（很多展会有免费的参展商清单）、Google Maps 搜「tyre importer / 城市名」、LinkedIn 搜「procurement / purchasing manager + 国家」。付费海关数据？等你出第一单再说。
  3. **整理成 CSV（10 分钟）**：存成 `my_leads.csv` 放仓库根目录，表头就这串：`company,country,product,source,email,phone,years,contact,note`。
     - `source` 只能填 `referral` / `trade_show` / `customs` / `linkedin` / `search` 里的一个（这项最影响分数，最高 30 分）。**填成 `google` 或者留空，都按最低的 10 分算**。
     - `years` 留空会被当成 0（最多少拿 10 分），不知道就先空着，Day 2 背调时再补。
- **怎么算过关**：一个 ≥10 行的 CSV，`company` 列每行都有值，`source` 列每行都是上面那五个合法值之一。
- **今天先别干的事**：别开始写开发信，也别纠结模板长啥样。

## Day 2 · 背调 + 补联系方式 + 自动分级（≤2 小时）

- **今天做什么**：
  1. **L1 筛查（40 分钟）**：按 [`03-due-diligence.md`](03-due-diligence.md) 的 L1 三件事（官网存在？成立年份？社媒活跃？）逐条过，任一不过直接淘汰，并把查到的 `years` 补进 CSV。
  2. **补联系方式（40 分钟）**：给留下的公司补邮箱 / 电话 / WhatsApp。补不到就如实留空——脚本会把它降到 T2/T3，这比瞎填一个错邮箱强（**邮箱格式不对会被倒扣 18 分**）。
  3. **跑分级（5 分钟）**：

     ```bash
     python scripts/lead_score.py my_leads.csv
     ```

     想看每条为什么得这个分，加 `--format detail`：

     ```bash
     python scripts/lead_score.py my_leads.csv --format detail
     ```

- **做完的标志**：屏幕出现分级表 + 底部 `汇总: T0:x / T1:x / T2:x / T3:x`，并且你能说出「先回谁」（T0）和「先打谁」（T1）。
- **提前剧透一个大概率事件**：**新手第一份 CSV 跑出来 T0 是 0 条，太正常了。** `source=search` 才 10 分，只有一个邮箱才 28 分，就算信号和成熟度全拉满，也够不着 T0 那条 80 分线。
  - **T0 = 0 不算失败，也不是让你回去重找。** 分级是为了排先后顺序，不是发准入证。Day 3 照样发，只是发给 T1 里分数最高的那几家。
  - 真正该做的：下周把 `source` 从 `search` 往 `linkedin` / `trade_show` 挪，T0 自己就冒出来了。

## Day 3 · 首触（今天是硬底线，必须发出去）（≤2 小时）

- **今天做什么**：
  1. **生成文案（10 分钟）**，把落款换成你自己的：

     ```bash
     python scripts/outreach_gen.py my_leads.csv --tier T0 --sender "你的名字 | 你的公司" --lang en --out drafts_day3.md
     ```

     - 不加 `--sender` 时落款是 `[Your Name] | [Company]`——**那是占位符，必须替换**。
     - 如果 T0 是 0 条（Day 2 说过的常见情况），把 `--tier T0` 换成 `--tier T1`。
     - 屏幕只打印 `[T0] 本级无线索。` 不是脚本坏了，是这一级真没线索，换 `--tier T1` 再跑一次。
  2. **改那句「为什么是你」（40 分钟）**：脚本用 CSV 的 `note` 列拼一句只对这家公司成立的话。`note` 是空的就会退化成模板句——**这时你必须自己补**：刚参展？在招采购？发了 RFQ？官网某个产品页？写进 `note` 再重跑一次。
  3. **发出去（60 分钟）**：按 [`04-outreach.md`](04-outreach.md) 的渠道顺序，**LinkedIn / WhatsApp 先发，邮箱作为跟进**（邮箱进垃圾箱概率高）。**今天的目标是 3–5 家，不是全部。**
- **做完的标志**：`drafts_day3.md` 里至少 3 封已实际发出；每封那句「why them」换成同行就不成立；**全文没有出现价格**。把今天这个日期记下来，Day 4 要用。

> **Day 3 是整条路径的硬底线。** 这一天发不出去，前面两天找的名单就只是名单——不是生意。发出去的烂信 > 存在本地的完美信，因为只有前者能给你真反馈。

## Day 4 · 第 2 次触达（换渠道）+ 继续补线索（≤2 小时）

- **今天做什么**：
  1. **生成跟进计划（5 分钟）**。`--start` 填你 **Day 3 实际首发那天的日期**，格式 `YYYY-MM-DD`。不知道今天是几号先查一下：

     ```bash
     python -c "import datetime;print(datetime.date.today())"
     python scripts/followup_plan.py --tier T0 --start 2026-10-08 --csv my_leads.csv
     ```

     上面 `2026-10-08` 只是示例，**请换成你自己的首发日**（macOS / Linux 也可以直接用 `date +%F`）。T0 的节奏是 **D0 / D2 / D5**——首发当天、第 2 天后、第 5 天后，共 3 次，**不是每天发一次**。
  2. **执行 D2 那一次（60 分钟）**：换一个渠道（昨天邮件 → 今天 WhatsApp / LinkedIn），诉求不变，但**必须带一条新信息**（配柜量参考 / 一个规格细节 / 一条行情）。不要原封不动再发一遍。
  3. **继续补线索（30 分钟）**：顺手再补 5–10 条进 `my_leads.csv`。名单是复利资产，不要只在 Day 1 找一次。
- **做完的标志**：D2 触达已发；`my_leads.csv` 比昨天多 ≥5 行；收到的回复（哪怕是 "not interested"）已记进 `note` 列——**回复本身就是信号，被拒绝也要记**。
- **第 3 次触达（D5）不在今天**：它落在首发后第 5 天，也就是 Day 8。这条 7 天路径到 Day 7 就收尾，所以 **Day 6 先把那条消息写好存在草稿箱，Day 8 早上发出去**——只要 10 分钟的事，别重新想文案。

---

## Day 5 · 换角度再发一批（把名单铺开，≤2 小时）

- **今天做什么**：
  1. **重跑分级（5 分钟）**：名单变了，分级也该重跑一次。

     ```bash
     python scripts/lead_score.py my_leads.csv
     ```

     新补进来的那 5–10 条里，大概率有几家跳进了 T0/T1。**这是这条路径最省力的一步**——比重新找客户快得多。
  2. **给新冒出来的 T0/T1 也发一轮（60 分钟）**：照 Day 3 那套走一遍（生成文案 → 改「为什么是你」→ 发）。**注意换渠道**，别和昨天同一批人用同一种方式撞上。
  3. **整理回复（30 分钟）**：把收到的每一条回复记进 `note` 列，写清楚是哪一类客户、回了什么。回 "not interested" 也记——它告诉你该换钩子还是该换名单。
  4. **看哪一类在回（25 分钟）**：按 `source` / 国家 / 产品分个组，看哪一类有回音，下周就把力气往这一类上使。
- **做完的标志**：新补的线索里至少 1 家已被触达；回复全部记进 `note`；你能说出「哪一类客户在回」。

---

## Day 6 · 写好第 3 封信 + 收尾复盘（≤2 小时）

- **今天做什么**：
  1. **把 Day 8 那封信写完（30 分钟）**：给对方一个台阶——「这条路先放着，你随时找我」，再带一条对他有用的行业信息。**今天写好存草稿，Day 8 早上只管发**。写完就别再改了。
  2. **算三个数（15 分钟）**：发出去多少条、收到几封回复、回复率多少。**回 1 封是正样本，回 0 封也是有效数据**——它说明钩子或名单有问题，换一个再试。
  3. **写 3 行复盘（30 分钟）**：哪一类客户在回 / 哪一句钩子有用 / 下周只主攻哪一类。
  4. **定下周动作（45 分钟）**：名单补到多少条、哪一类客户主攻、下周哪天发第二轮。**写进日历**，别靠脑子记。
- **做完的标志**：Day 8 那封信已在草稿箱；有「发出 / 回复 / 回复率」三个数字；写下下周主攻的客户类型。

## Day 7 · 收官：这份结果就是你的第一份外贸证据（≤2 小时）

- **今天做什么**：
  1. **把这一周存成档案（30 分钟）**：分级结果、跟进表、草稿、三个数字，存到一个文件夹里。**这不是浪费，这是你申请学校、写简历、复盘时唯一拿得出手的东西**——比任何课程证书都硬，因为它带日期、带数字、带你自己的操作记录。
  2. **补上这一周欠的账（60 分钟）**：名单不到 20 条就补到 20 条；`source` 全是 `search` 的，下周把几家挪成 `linkedin` / `trade_show` 再跑一遍分级，看看 T0 会不会冒出来。
  3. **挑一条反馈回去（30 分钟）**：哪一句钩子有用、哪一步你卡住了，写成一条 Issue 提上去。**你踩的坑正好是下一个人要绕的坑。**
- **做完的标志**：这一周的档案存好了；下周的动作写进日历；至少提了 1 条反馈（或者明确记下「这周什么都不想提」——那也正常）。

## 这条路跑完，你手上应该有什么（可验收清单）

把下面这 6 项当成这条路径的交付物。缺哪项回去补哪项——**别带着缺口就开第二轮**：

1. **一份 ≥20 行的 `my_leads.csv`**：每行至少一种联系方式，`source` 列全部合法，淘汰掉的皮包公司已删或已标注。
2. **一张 T0–T3 分级结果**：能说出「先回谁 / 先打谁 / 谁先养着」。想存档就跑 `python scripts/lead_score.py my_leads.csv --format json --out scored.json`。
3. **至少 5 封已发出的首触消息**：存在 `drafts_day3.md`（或你自己的草稿文件）里，每封带一句只对这家公司成立的话。
4. **一份跟进计划表**：`python scripts/followup_plan.py --tier T0 --start 你的首发日 --csv my_leads.csv --format csv --out followup_plan.csv`，3 次触达的日期已写进日历。
5. **三个数字 + 3 行复盘**：发出 / 回复 / 回复率，以及下周主攻哪一类客户。
6. **一份能拿出手的档案**：这一周的分级结果、跟进表、草稿、三个数字，存成一个文件夹。申请学校、写简历、跟人讲你做过什么的时候，它比任何课程证书都硬——**它带日期、带数字、带你自己的操作记录**。

> **「收到回复」不在交付物清单里。** 那是结果，不是动作。上面 6 项做扎实了，它出现的概率才会往上走。

## 如果第 3 天你还没动静：对号入座，别放弃

卡住是正常的，先找症状再补救：

| 卡在哪 | 症状 | 今天就做的补救 |
| --- | --- | --- |
| 选市场 | Day 1 结束还定不下国家 | **今天就随便定一个**（英语优先）。市场选错下周能换，卡着不动是唯一真实的损失 |
| 找线索 | 找来找去不到 10 条 | 缩到一个城市 + 一个品类，光 Google Maps 一路也能出 10 条；或者今天先收 5 条，明天补 |
| 分级 | 跑出来全是 T2/T3 | 说明 `source` 太弱、联系方式不全。**照发 T1/T2 里分数最高的 3 家**，同时把 `source` 往 `linkedin` / `trade_show` 挪 |
| 首触 | 文案改了三小时还没发 | **今天的目标只是发出 3 封**。发出去的烂信 > 存在本地的完美信，只有前者能给你真反馈 |
| 全都没做 | Day 3 结束一条都没发出去 | 砍掉一半：今天只做「定 1 个国家 + 找 5 条 + 发 3 封」，2 小时够。**路径可以压缩，不能跳过** |

**唯一不能妥协的一条**：7 天内至少有 3 条消息真的发给了真实的人。没发就没有数据，后面所有复盘都是自欺欺人。

## 为什么这条路径比「闷头写 200 封开发信」靠谱

传统做法把「写邮件」当核心。这条路径把核心换成三件事：

1. **顺序**：先筛（T0/T1）再发，不把时间花在垃圾线索上。
2. **通道**：LinkedIn / WhatsApp 首触，邮箱跟进，绕开垃圾箱。
3. **信号**：每条都带一个具体钩子（刚参展 / 在招采购 / 发了 RFQ），不是「希望和您合作」。

做到这三点，**回应的概率会上升**——但上升多少取决于你的产品、市场和时机。这里不给数字，也不给保证。能确定的是：做完这 7 天你会拿到真实数据，而不是一堆自我感觉。

- **提 PR / 反馈**：遇到写错、跑不通、或想补一段对新手更友好的内容，看仓库里的 `CONTRIBUTING.md` 和 `STAR-GROWTH.md`，按格式提 Issue 或 Pull Request。哪怕只改一个错别字，对下一个零基础用户都是帮助。
- **分享**：把项目转发给同样想做外贸、但卡在「不会写开发信 / 不懂怎么找客户」的朋友，比单纯收藏更有用。
- **回来补一条**：你卡在哪一天、是怎么绕过去的——这比 star 更有价值，直接提 Issue 就行。
