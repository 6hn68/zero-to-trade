# 03·背调客户 Due Diligence

> 背调这步，一句话：给每条线索打 A/B/C，把皮包公司和骗子提前剔出去，把好钢用在能成交的买家身上。
>
> 原理很土——一封开发信不值钱，但浪费在假客户身上的三个月很贵。先筛后打，这是外贸唯一省钱的打法。
>
> 背调只管两件事：①这家值不值得你花时间；②第一句话从哪开口（一句能当着他面念的证据，回写进线索表的 `note` 列，建联环节直接变成开发信的第一句）。
>
> 这两件事答不上来，你写的就不是背调，是一份没人会看的作文。

## 一、为什么这一步排在最前

新手最爱犯的错：把「有人回了邮件」当成「客户到手了」。

现实里会让你付出代价的，不是没人回信，而是：
- 你花两周认真准备报价、算了成本、报了价格，对方根本不是买家，是同行来套价
- 你发了三封跟进、附了详细规格，对方收完就没了，连一句「不合适」都不回
- 你按他的要求寄了样品，快递已经发出去了，才发现自己连对方公司是不是真的都不知道

这几笔账加起来，差不多决定你能不能熬过前六个月。

背调的核心就一句：用最少的时间，把明显不靠谱的先扔出去。A 类能赚钱，C 类会耗死你——而 C 类的破绽，往往两分钟就露出来。

## 二、合规红线（先看这条）

只用那些你光明正大能打开的公开来源。

允许的：

- 企业官方网站（公司信息、产品目录、联系方式、成立声明）
- 公开海关/进出口数据（UN Comtrade、各国官方统计机构、持牌商业数据平台的公开查询功能）
- LinkedIn 公开主页（职位、公司信息、公开动态）
- 公开的展会参展商名录与行业协会会员名录
- 公司官方渠道发布的新闻稿、社媒官方账号
- 公开的企业注册信息（目标国官方商业登记机关的公开查询）
- 搜索引擎与公开网页缓存
- 客户主动发来的公司资料

下面这些，别碰：

- 付费购买、来路不明的「客户名单」「海关数据打包」——来源不明的数据往往来自泄露库或盗卖链条，用了要承担法律责任
- 任何声称能「破解海关数据」「导出客户邮箱」的服务
- 冒充对方身份去套取信息（伪装成同业、伪装成客户、伪装成快递）
- 未经同意获取、购买、拼接个人信息（私人手机号、私人邮箱、身份证件信息）
- 收买内部人员、贿赂对方员工获取客户名单与价格体系
- 抓取、镜像违反平台服务条款的网站内容
- 使用被盗数据库、被泄露的联系人名单

刑法红线（底线，不是建议）：

下面这些动作，无论多想成交都一律不做。它们不是「灰色手段」，而是《中华人民共和国刑法》第 253 条之一「侵犯公民个人信息罪」明摆着的打击对象——违反国家有关规定，向他人出售、提供、窃取或以其他方法非法获取公民个人信息，情节严重的要追究刑事责任（具体量刑以现行法条和司法解释为准）：

- 社工库、撞库数据，以及任何「输入手机号就能查到本人」的查询服务
- 开房记录、住宿记录、出行记录、通话记录、**定位轨迹**
- **银行流水**、征信报告、社保/公积金记录
- **补卡查号**、通过运营商或快递内部关系调取他人信息
- 收买、指使对方公司员工（「内鬼」）泄露客户名单、价格体系、合同
- 人肉搜索、扒对方家人与私人社交账号、把碎片化的私人信息拼成档案

划条线：你查的是「公司的公开经营信息」，不是「某个人的私人生活」。一旦你盯的对象从公司滑到了具体的人，就已经越线了。

原则也简单：能光明正大打开的网页，才算数。一个信息要「特殊手段」才拿得到，那就别用，也别写进档案。

坐牢这件事不在外贸 ROI 的账本里——这笔账，别算反了。

背调的结论是给内部决策用的，不是用来评判、举报、传播别人的信息。

## 三、背调只回答两个问题

先把目的钉死，后面所有的动作才有边界：

1. **这家值不值得你花时间？** → 产出 A/B/C 评级（定义见本页评级标准表，映射口径见 [04·建联客户](./04-outreach.md)）。
2. **第一句话从哪儿开口？** → 产出一句「只对这家公司成立」的证据，回写进线索表的 `note` 列，直接变成开发信的 why-them 那句话。

背调不负责三件事：

- 不产出一份完整报告。查不完，也不需要查完——客户档案是跟出来的，不是查出来的。
- 不评判对方「好不好、是不是骗子」。只记录信号和处置动作，不写道德判断，不外传。
- 不查任何自然人的私人信息（见第二节刑法红线）。

背调做没做完，就一个标准：你能不能一句话说清「为什么是这家、第一句从哪开口」。说不清，就是还没做完。

## 四、七维度清单：去哪查 / 什么算红旗

按这个顺序查。前三项定「是不是真公司、真买家」，后四项定「值不值得打、怎么开口」。

| # | 维度 | 去哪查（公开源） | 查到什么算红旗 |
|---|---|---|---|
| 1 | **身份履历**：公司真实存在吗？注册名和自称名一致吗？ | 目标国官方商业登记机关的公开查询（如英国 Companies House、香港公司注册处查册中心、目标国工商/商务主管部门公开门户）；官网 About / Imprint / 页脚公司信息；搜索引擎搜公司全名 | 查不到任何注册实体；注册名与自称名对不上且无解释；成立不足一年却自称「数十年历史」 |
| 2 | **规模体量**：多少人、多少点、多大盘子？ | 官网 About / 门店地图 / 产品目录；LinkedIn 公司页显示的员工数区间；展会参展商名录；行业协会会员名录 | 官网宣称「200+ outlets」但 LinkedIn 显示员工个位数；门店地图全是空白或占位；规模数字只有官网一处来源、无处交叉 |
| 3 | **渠道角色**：进口商 / 一级批发 / 二级批发 / 零售 / 车队自用？ | 官网 distributor / wholesale / dealer / import 等自述；产品目录里的品牌数（多品牌 = 分销，单一自有品牌 = 同行）；行业协会会员名录 | 自称 distributor 却没有任何下游渠道证据；本身是同行品牌商（套价风险，不给报价单）；角色与你的价格带不匹配（打车队的价格去谈进口商，白谈） |
| 4 | **进口足迹**：真在进口吗？品类对得上吗？ | UN Comtrade（comtradeplus.un.org）；各国官方统计/海关公开查询；持牌商业数据平台的公开查询功能；目标国政府采购公开门户的招投标公告 | 零进口记录；进口品类与你的产品无关；多年只有零星一单（有记录但不成规模）；只有出口没有进口 |
| 5 | **信用与风险信号**：有官司、有执行、在制裁名单上吗？ | 目标国法院/司法公开检索；企业信用公示类公开平台；Google News 搜「公司名 + lawsuit / bankruptcy / fraud」；OFAC / EU / UN 公开制裁名单检索 | 有被执行、失信、破产清算记录 → 降级且不做任何赊销；**出现在制裁名单 → 立即终止，不接触、不报价、不寄样** |
| 6 | **关键人是谁**：谁能拍板？怎么联系？ | LinkedIn 公司页 People 标签（找 purchasing / procurement / sourcing 岗）；官网 Team / Contact 页；展会演讲与嘉宾名单；公司社媒官方账号 | LinkedIn 无真实员工或只有老板一人；完全没有采购/供应链岗位；唯一联系方式是 info@ 或免费邮箱 |
| 7 | **最近在做什么**：有什么能当开口的由头？ | 官网 News / Products 的更新时间；LinkedIn 公司动态；社媒官方账号；近两年展会参展年份；近期招投标公告 | 官网最后更新停在数年前；近期动态全是招聘与鸡汤、无业务动作；近两年无任何新品、参展、投标痕迹 |

补一个 30 秒就能做完的核查：**邮箱域名**。免费邮箱（gmail / yahoo / hotmail / outlook / qq / 163 等）是唯一联系方式 → 红旗；邮箱域名与官网域名不一致 → 红旗。

> 七个维度共一条规矩：查不到就写「未查到」，别写「没有」。查不到不等于不存在；降级得写明是哪项没查到，不然下次重查又踩同一个坑。

## 五、分步操作（三级漏斗 + 时间盒）

时间盒（写死，到点就走。新人最容易在这上面无限深挖）：

| 层级 | 单条上限 | 谁要做 | 到点动作 |
|---|---|---|---|
| L1 筛查 | **2 分钟** | 所有新线索 | 不过就定 C，写一句理由，走人 |
| L2 标准 | **10 分钟** | L1 通过的 | 出 A/B/C + 一句 `note` |
| L3 深度 | **30 分钟**（硬上限 45） | **仅 A 类** | 出 5 行档案，写完立刻进建联 |
| **单家总计** | **45 分钟硬顶** | — | 到点还查不完 = 信息不足，按现有证据先定级，留到跟进时补 |

> 漏斗查的就是上面那七个维度，只是粗细不同：L1 扫表层、L2 做交叉、L3 补深度。别在漏斗外面自己另搞一套——你查到凌晨三点，多半就是在发明新查法。背调 45 分钟够了，再往下挖你不是在背调，是在 stalking。

**L1 筛查：2 分钟过一条，先把明显不靠谱的扔掉**

只查四个问题，任何一个答不上来就先降为 C 级：（全项目统一口径：L1 四问。别的速查文档要是写成三问，以这里四问为准。）

1. **网站活着吗？** 打开首页，能加载，最近有更新痕迹（新闻、新闻稿、产品页）。打不开、只有Coming soon、停在 2019 年 → 直接降级
2. **有地址和联系方式吗？** 物理地址 + 域名邮箱（不是只有 gmail）。只有 WhatsApp 一个号码的降级但不毙（小国常态）
3. **有批发/贸易属性吗？** 网站上出现 distributor、wholesale、trading、import、dealer、supply 等词，或产品目录里品类多品牌
4. **有规模迹象吗？** 员工数、门店数、成立年份、覆盖区域。一点迹象都没有的，谨慎

L1 产出：一条不值得再查的，当场定 C、写清理由、进下一条。压掉几条没标准答案，看你名单质量——别为了凑数把 C 类放进来。

**L2 标准：10 分钟过一条，判断「值不值得投入」**

给剩下的做四项核对：

1. **与海关/贸易数据交叉**：这家公司有真实进口记录吗？进口品类跟你对得上吗？频率合理吗？（老客户每年都在进口 = 好信号；三年只有一单 = 谨慎）
2. **官网自述交叉**：官网说自己是什么，和贸易数据里它的行为矛盾吗？一个自称「我们是 GCC 最大轮胎分销商」的公司，贸易记录一年只进口 2 个柜，矛盾
3. **联系方式一致性**：官网的邮箱域名、公司官网名、LinkedIn 公司名一致吗？不一致要问为什么
4. **人员层信息**：LinkedIn 上有几个人、有没有采购岗？公司是「一个老板」还是「有团队」？（提醒一句：LinkedIn 上写 CEO 的未必真是 CEO，但一定很想让你以为他是——头衔当参考，别当证据。）

L2 产出：分出 A/B/C。

**评级标准（照抄可用）：**

| 评级 | 判定 | 处理 |
|---|---|---|
| **A** | L1 全过 + 有进口记录 + 品类匹配 + 找到具体采购人 | 48 小时内首触，投人 |
| **B** | L1 全过 + 品类基本匹配 + 找得到联系人但采购证据弱 | 进 T1/T2 序列，先用低成本方式试 |
| **C** | 任何一项 L1 不过，或联系方式残缺，或信息自相矛盾 | 不主动投人，只放低频内容养着 |

**L3 深度：只对 A 类做，30 分钟（硬上限 45）**

A 类才值得做深度，动作四项：

1. **规模画像**：大概进口体量、可能覆盖的渠道类型（批发给谁、零售还是车队）
2. **决策链判断**：Owner 直采 / 采购经理 / 贸易公司代采（中东常见的两层结构：进口商 + 二级批发）
3. **现状切口**：他现在在卖谁家的货？官网展示的品牌有哪些？新产品是哪个型号正在推？——这决定你开发信的角度
4. **风险清点**：成立时间很短就要求大额信用额度、只接受 FCA/EXW 且拒绝任何预付、地址是邮箱/虚拟办公室、公司名在搜索里完全没有其他痕迹

L3 产出：一份 5 行档案，直接决定开发信怎么写。第 5 行「开发信角度」必填——这行空着，L3 等于白做。

---

回写：把结论写进线索表（这步不做，前面全白干）

背调的产出必须落到 CSV 的这几列里，否则它只是一段会忘掉的记忆：

| 线索表列 | 写什么 | 谁在读 |
|---|---|---|
| `note` | 一句**可以当着对方念出来**的证据，用英文写，如 `Importer record: 6 shipments/year from Asia, 40HQ container` | `lead_score.py` 会扫描它算「采购信号」分；`outreach_gen.py` 会把它**原样拼进开发信**的 why-them 句 |
| `contact` | 背调找到的关键人角色（purchasing manager / buyer / owner） | `lead_score.py` 参与关键词命中；`outreach_gen.py` 用作称呼 |
| `source` | 换成背调后最可信的那个来源（`customs` > `trade_show` > `linkedin` > `search`） | `lead_score.py` 的「来源可信度」占 30 分，仅次于联系方式 |
| `years` | 注册/成立年数（查不到就留空，别猜） | 成熟度分 |

写 `note` 两条规矩：

1. **只写可以对外说的话。** `outreach_gen.py` 会把 `note` 原样插进英文邮件（"your note mentioned: …"），所以内部判断（「疑似皮包」「可能是同行套价」）**绝对不能写在这一列**——另存到自建的 `risk` 列或内部备注区。
2. **用事实词，不堆关键词刷分。** `rfq / quotation / container / 40HQ / purchasing manager` 这类词会命中采购信号加分，但只有真有证据时才写；编出来的关键词只会让你自己误判优先级。

回写后跑一遍，看分级有没有变化：

```bash
python scripts/lead_score.py my_leads.csv
python scripts/outreach_gen.py my_leads.csv --tier T0
```

A/B/C 与 T0-T3 的映射口径见 [04·建联客户](./04-outreach.md)（C 一律不进主动建联序列）。

## 六、红旗清单与处置动作

下面任一信号出现，照「处置」列办，别靠拍脑袋临时起意：

| 信号 | 处置 |
|---|---|
| 唯一联系方式是免费邮箱 | 降为 B，先补到域名邮箱再回来 |
| 邮箱域名与官网域名不一致 | 降级，先问清主体关系（子公司 / 品牌名？） |
| 官网多年未更新 / 只有 Coming soon / 明显模板站文案 | 降为 C |
| 只有一个 WhatsApp 号，无地址、无官网 | 降为 C（小国可留观察池，但**不给任何账期**） |
| 公司名与注册名对不上 | 暂停，先做身份核对，要求对方书面澄清主体 |
| LinkedIn 无真实员工、无采购岗 | 降为 B |
| 有被执行 / 失信 / 破产记录 | 降为 C，且**只做预付或即期信用证** |
| **出现在制裁名单上** | **立即终止**：不接触、不报价、不寄样 |
| 零进口记录却自称大分销商 | 降为 B/C，按「企业真实但商业证据不足」处理 |
| 本身是同行品牌商 | 转同行处理流程，**不给报价单** |
| 首次接触就要大额账期 / 只接受 EXW-FCA 且拒绝任何预付 | 降级，只做预付或即期 L/C |
| 地址是邮箱地址 / 虚拟办公室 | 降级，要求提供可核实的实际地址再谈样品 |
| 要求把货款付到与合同主体不一致的第三方账户 | **直接终止**——这是最典型的贸易诈骗手法，不是谈判问题 |

## 七、判断标准

本环节「做好了」的硬标准：

- 全部信息源**公开合法**，无任何付费黑名单数据、灰色渠道、冒充套取。
- L1 四问逐条判定留痕；L2 已完成，进口记录与官网自述的矛盾点已逐条处理（降级或剔除）。
- 每条线索都有 **A/B/C 评级**及理由（A/B/C 定义见本环节评级标准表）。
- A 类已完成 L3 深度档案（含决策链判断 + 切入点），48 小时内可进入建联。
- 红旗清单已建立，敏感个人信息仅用于内部销售决策、不外传。
- **时间盒守住了**：单家总耗时 ≤ 45 分钟，L3 只做在 A 类上（超时 = 本环节没做好）。
- **已回写**：每条 A/B 线索的 `note` 都有一句可对外说的证据，`source` 已更新为背调后最可信来源；内部风险判断不写在 `note` 里。
- 每条线索的处置动作已定（进建联 / 降级 / 终止），不是只填了个字母。

## 八、AI 提示词

**提示词 1：单客户快速背调（L1/L2）**

```
You are a due-diligence analyst for B2B export sales (Chinese tire manufacturer). Using ONLY the
public information I paste below, assess this company. Strictly no outside guesses.

INPUT DATA (company name, country, website text, customs/import records, LinkedIn snippets):

OUTPUT in this exact format — keep each section under 80 words:

1. IDENTITY
   Legal name / trading name / whether they are importer, distributor, retailer, or garage chain
   (quote evidence for each claim)

2. PHYSICAL PRESENCE
   Address found / address type (own office, workshop, PO box, virtual office) / branch count
   Say "NOT STATED" if absent.

3. BUSINESS SIGNALS
   Product range overlap with {TBR / OTR / PCR tires} / brands they carry / wholesale terms
   mentioned / years active / size signals (employees, locations, annual turnover if disclosed)

4. TRADE BEHAVIOUR CROSS-CHECK
   Compare what the company CLAIMS about itself with what the import records SHOW.
   Explicitly flag every contradiction. If no import records were provided, write
   "NO TRADE DATA PROVIDED — cannot verify".

5. CONTACTABILITY
   Named person? / role? / verified-looking email? / phone/WhatsApp? / LinkedIn profile?
   If only a generic mailbox exists, say so.

6. RED FLAGS (list as bullets, each one sentence)
   Examples to check: domain age unknown but company claims decades of history; only gmail contact;
   address not verifiable; asks for credit terms on first contact; brand claims impossible for
   their size; website content looks AI-generated boilerplate; company name barely appears
   anywhere else on the web.

7. VERDICT
   Grade A / B / C with ONE sentence reason and ONE concrete next action.

RULES: Use only what I provided. Never invent an email, phone, address, or figure. If a fact is
absent, "NOT STATED" is the correct answer and more useful to me than a plausible guess.
All information here will be used for internal sales prioritization, so accuracy matters more
than completeness.
```

中文说明：这段的精髓在第 4 节和第 6 节——逼 AI 把「对方自述」和「实际贸易行为」摆一起对撞，再把红旗列成清单。骗子和小皮包，基本都在这两处露馅。

**提示词 2：A 类客户深度档案（L3）**

```
Act as a Key Account Manager preparing an account plan BEFORE the first outreach.

Company: {name}, {country}. All verified facts I collected: {paste your verified notes}

Produce a strict one-page account plan, in this order:

SECTION 1 — SNAPSHOT
Table: Legal entity | Type (importer/distributor/retailer/fleet) | Est. import scale |
Likely decision-maker role | Our product fit (high/medium/low) | One-line strategic note

SECTION 2 — DECISION CHAIN
Map the likely buying chain for this market: who signs the contract, who specifies specs,
who pays, who receives goods. For GCC-type markets, explicitly state whether a two-tier
structure (importer + secondary wholesaler) is likely. Name the ROLES I should target, not
invented person names.

SECTION 3 — CURRENT SUPPLY SITUATION
Only using provided facts + clearly-labelled assumptions: which brands they likely carry,
what spec categories they must move, what a new supplier must beat on (price? lead time?
warranty? documentation?).

SECTION 4 — OPENING ANGLES (max 3)
Each angle: one sentence hook + the single piece of evidence that makes it credible + the
question I should ask them to make them reply.

SECTION 5 — DEAL KILLERS
3 reasons this deal could still die, and the earliest signal that would tell me to stop.

RULES: Every claim must be tagged [VERIFIED] (I gave you the fact) or [ASSUMPTION] (your
inference). No unlabelled statements. Do not invent people, certifications, tariffs or numbers.
```

中文说明：重点是 [VERIFIED] / [ASSUMPTION] 标签——逼 AI 把「你给的事实」和「它的推断」分开，你一眼就能看出哪句得自己再核一遍。SECTION 4 的「钩子 + 证据 + 问题」，可以直接变成开发信第一句。

**提示词 3：批次分级与配额分配**

```
You are sales operations planning. Below are 60 leads with their L1/L2 verification results.
I have limited capacity: roughly 8 hours of research and outreach per week.

Allocate my time, not just grade them.

Deliver:
1. Grade A / B / C counts and total estimated hours to complete L3 on each A
2. A 4-week calendar: Week 1-2 = L3 on which A accounts and why these first (rank by
   "expected value per hour" = (deal size × probability) / hours spent)
3. Which accounts to deliberately DROP despite looking attractive, with the reason
   (bad signal, too slow, requires credit risk you can't carry, etc.)
4. A red-flag watchlist: accounts that look fine on the surface but have one worrying signal —
   flag with the exact signal and what to verify next time we talk

Rules: Use only the verification results I provided. If two accounts are tied, prefer the one
with clearer verified evidence over the one with bigger-sounding size claims.
```

中文说明：这段把「分级」变成「资源分配」。新手的通病是把 A 类全做一遍，结果每家都没做透。真取舍是算清每小时的期望价值，主动放弃几家看着诱人的。

- [ ] 未触碰刑法红线：社工库、开房/出行/通话记录、定位、银行流水、补卡、内鬼买数据——一项都没有

- [ ] 七维度逐项过过，查不到的已写「未查到」，没被当成「没有」
- [ ] L2 已完成，进口记录与官网自述的矛盾点已逐条列出并处理（降级或剔除）
- [ ] 每条线索都有 A/B/C 评级，评级理由写进备注

- [ ] 红旗清单已建立，每条红旗都配了处置动作（降级 / 暂停 / 终止）

## 十、新手常见坑

**坑 1：不背调，先发信试试**
- 现象：拿到 200 条名单，选了看起来最大的 50 家当天全发出去。
- 原因：觉得背调浪费时间，「发出去看看有没有回复」更快。
- 正确做法：至少先过 L1 的两个问题（网站活不活、有没有贸易属性）。2 分钟筛一条，200 条也就一小时。寄样品的钱比这贵一百倍。

**坑 2：买「海关数据客户名单」**
- 现象：花几百块买了一包「中东轮胎客户名单」，两千个邮箱，看着特别值。
- 原因：这些数据来源不明，很多是从泄露数据库流出的，或者干脆是编的邮箱格式。
- 正确做法：只用可公开检索的贸易数据平台功能和公开来源。数据来源不明 = 法律风险 + 高退信率 + 域名信誉受损。

**坑 3：只查「有没有这家公司」，不查「它是不是买家」**
- 现象：确认了公司真实存在，评级就给了 A。
- 原因：把「企业真实」和「商业真实」混为一谈。很多公司真实存在，但根本不进口，或者不做你这类产品。
- 正确做法：企业存在只是入场券，进口记录/贸易行为才是评级依据。真实存在但零贸易信号 → 最多 B。

**坑 4：相信官网上的自我宣传**
- 现象：官网写着「leading distributor in GCC with 200+ outlets」，直接标 A。
- 原因：这句话谁都能写，且可能是模板站生成的。
- 正确做法：所有自我宣传的数字都标为「公司自述」，找第三方数据交叉（海关记录、展会参展规模、LinkedIn 员工数）。对不上就降级，不必戳穿。

**坑 5：背调做成学术研究**
- 现象：一条线索查了 40 分钟，查到凌晨，还没建联。
- 原因：把「充分」当「正确」，追求查无遗细。
- 正确做法：按第五节的时间盒表执行（L1 两分钟、L2 十分钟、L3 三十分钟，单家总计 45 分钟硬顶）。到点就走。A 类客户的价值在后续跟进里体现，不在背调里。

**坑 6：把背调结论当「判断对方的权力」**
- 现象：内部讨论时说「这家在骗人」「这家肯定不行」。
- 原因：背调结论容易带上情绪。
- 正确做法：背调只回答「值不值得投时间」，不回答「这人好不好」。结论只写信号和处置动作，不写道德判断，也不外传、不传播。

**坑 7：把内部判断写进 `note`，脚本把它原样发给了客户**
- 现象：背调时在 `note` 列写了「疑似皮包 / 可能是同行套价 / 规模存疑」，跑完 `outreach_gen.py` 一看，英文邮件正文里赫然写着 "your note mentioned: 疑似皮包"。
- 原因：不知道 `outreach_gen.py` 会把 `note` 原样拼进开发信的 why-them 句（见 `outreach_gen.py:build_why_them`）。
- 正确做法：`note` 只写**可对外说的一句证据**，用英文写；内部风险判断另存到自建的 `risk` 列或内部备注区。生成文案后逐封过一遍英文正文再发。

**坑 8：把「没查到」当成「没有」**
- 现象：LinkedIn 上没找到员工，就写「无员工 = 空壳」，直接毙掉。
- 原因：很多中小买家（尤其小国、家族企业）就是没有 LinkedIn 公司页，查不到不等于不存在。
- 正确做法：结论一律写「未查到（渠道：LinkedIn）」，再补一个替代渠道交叉（官网 Team 页、展会名录、海关记录）。只有**多个渠道都查不到**才算信号。
