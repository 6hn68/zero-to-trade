> 콜드 메일 200통을 보냈는데 답장이 0통이라면, 문제는 영어가 아닙니다. 일의 순서입니다.
>
> 이 저장소는 "수출을 시작한다"는 막연한 말을 실제로 손에 잡히는 일로 바꿔 줍니다. 오늘 오후 어느 사이트를 열지, 거기에 무엇을 입력할지, 어떤 결과가 나오면 통과인지까지.

> 여기 있는 모든 것의 밑바탕에는 규칙 하나가 있습니다. **힘든 일은 AI가, 판단은 당신이.**

사야 할 강의도, 유료 플랜도, 이메일 입력 벽도 없습니다. MIT 라이선스, V20.

## 7단계 데모: 2분 만에 실제 리스트를 등급별로 나누고 첫 영업 메일 쓰기

문서를 먼저 읽을 필요는 없습니다. 일곱 단계, 단계마다 설명 한 줄과 복사해 붙여 넣을 명령 하나. 처음부터 끝까지 2분 정도면 됩니다. 아래 일곱 개 명령은 모두 이 저장소에서 실제로 실행해 본 것입니다(2026-11-24, Python 3.x, 표준 라이브러리만 사용). 샘플 데이터는 가상이며, 회사명 앞에는 【示例】("샘플") 접두어가 붙어 있습니다.

| 단계 | 한 줄 설명 | 명령 (복사해서 붙여 넣기) |
|---|---|---|
| 1 리스트 준비 | 샘플을 내 파일로 복사합니다. 실제 리드는 이 복사본에만 넣으세요 | `cp examples/leads_example.csv my_leads.csv` |
| 2 등급 나누기 | 리드 10곳을 T0–T3로 분류합니다. 그중 2곳에는 오늘 연락하세요 | `python scripts/lead_score.py my_leads.csv` |
| 3 T0 검증 | 메일을 쓰기 전에 T0가 유령 회사가 아닌지 확인합니다. 직접 넣지 않은 정보는 모두 "확인 필요"로 돌아옵니다 | `python scripts/due_diligence.py --company "【示例】海湾轮胎贸易"` |
| 4 첫 연락 작성 | T0 등급용 영업 메일 초안. 영문은 발송용, 중문은 본인 검토용 | `python scripts/outreach_gen.py my_leads.csv --tier T0` |
| 5 후속 연락 계획 | D0/D2/D5 리듬: 6일간 3회 연락, 세 번째에도 답이 없으면 멈춥니다 | `python scripts/followup_plan.py --tier T0 --start 2026-11-24 --csv my_leads.csv` |
| 6 답이 오면 견적 | 원가 + 운임 + 마진 → FOB/CIF 가격대 + 3단계 양보안 | `python scripts/quote_engine.py --cost 28 --freight 6 --margin 15` |
| 7 연락이 끊기면 재촉 | 견적 후 7일간 답이 없으면 진행 상황을 묻습니다. 단호하게, 절박하지 않게 | `python scripts/nudge.py --day D7 --scenario quoted` |

4단계를 마치면 실제로 보낼 수 있는 첫 연락 메일이 손에 쥐어지고, 5단계를 마치면 앞으로 6일 동안 매일 무엇을 해야 할지 알게 됩니다.

Python이 없으신가요? 웹사이트 [6hn68.github.io/zero-to-trade](https://6hn68.github.io/zero-to-trade/)를 여세요(로컬 복사본이라면 [`index.html`](index.html)을 더블클릭해도 됩니다). 리드 점수, 영업 메일, 후속 연락 계획, 견적까지 브라우저에서 돌아가는 도구 네 가지가 스크립트와 똑같은 규칙으로 작동하며, 인터페이스는 12개 언어를 지원합니다(오른쪽 위 메뉴). 샘플 리스트 불러오기 → 점수를 매겨 T0 찾기 → 첫 연락 메시지를 생성해 복사 → `[ ]` 자리표시자를 내 이름, 회사, WhatsApp으로 교체 → D0/D2/D5 후속 연락 계획 → 답이 오면 견적. 업로드되는 것은 없습니다. 리스트는 브라우저 밖으로 나가지 않습니다. 웹사이트의 첫 연락 문구는 영문과 중문 참고본으로 제공되며, 스페인어, 포르투갈어, 아랍어 문구가 필요하면 `outreach_gen.py --lang es/pt/ar`를 사용하세요.

## 이 저장소가 실제로 해결하는 것

"수출 어떻게 시작하나요"를 검색해 보세요. 누군가의 성공담 하나, SEO용 글 이백 개, 유료 강의의 무료 맛보기, 그리고 빨리 돈 버는 법을 약속하는 YouTube 썸네일이 나옵니다. 전부 읽고 나면 뭔가 알게 된 기분이 들지만, 다음 날 아침 통관 데이터 사이트 앞에서 첫 번째 칸에 뭘 넣어야 할지 몰라 멍하니 앉아 있게 됩니다.

정보가 부족한 게 아닙니다. 정보의 모양이 잘못된 겁니다. 조각조각 잘려 있고, 성공한 사람의 시점에서 쓰였으며, 정작 직접 손을 움직여야 하는 대목 바로 앞에서 끝나 버립니다.

대부분의 튜토리얼은 이런 식입니다. *"고객에 대해 배경 조사를 해야 합니다."* 그다음엔 *"배경 조사는 중요합니다."* 그리고 끝. 어떤 항목을, 어느 웹사이트에서, 무엇이 위험 신호이고, 어디까지 확인하면 충분한지는 여전히 모릅니다.

이 저장소는 정반대로 합니다. **하나의 일을 행동이 될 때까지 계속 쪼갭니다.**

| 튜토리얼의 말 | 이 저장소의 말 |
|---|---|
| "배경 조사를 하세요" | L1 선별, 세 가지 확인: 웹사이트가 존재하는가, 회사 등록 후 얼마나 됐는가, SNS 계정이 살아 있는가. 하나라도 탈락하면 그 리드는 끝입니다. |
| "양보다 질이 중요합니다" | 리드 10곳을 T0/T1/T2/T3로 나누고, 등급마다 다음 행동과 시간 예산이 따로 정해져 있습니다. |
| "후속 연락을 하세요" | 1일, 3일, 5일, 7일째. 매번 다른 각도로 접근하고, 7일째에는 결정으로 끝냅니다. 밀어붙일지, 접을지. |
| "AI가 무역을 바꾸고 있습니다" | 표준 라이브러리만 쓰는 Python 스크립트 열다섯 개(업무 스크립트 열네 개, 그중 하나는 견적 엔진, 그리고 개인정보 보호용 하나). `python scripts/lead_score.py examples/leads_example.csv` 한 줄이면 30초 만에 전체 등급 분류가 나옵니다. |

같은 정보, 다른 **입자 크기**. 차이는 그게 전부입니다. 여기 적힌 모든 주장은 한 가지 질문을 통과해야 합니다. 오늘 오후 무엇을 열고, 무엇을 입력하는가?

그러니 이건 동기부여 글이 아닙니다. 체크리스트와 스크립트 파일 열다섯 개(업무 스크립트 열네 개 + 개인정보 보호용 하나)입니다.

## 일곱 단계

처음부터 끝까지 하나로 이어진 사슬입니다. 나라를 고르는 데서 시작해, 통장에 돈이 들어오는 것으로 끝납니다. 단계마다 문서가 하나씩 있고, 모든 문서는 실제로 쓸 수 있는 결과물로 끝납니다.

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| **01 시장 고르기** | 언어, 수요, 장벽으로 점수 매기기 | 첫 시장 1곳 + 그 선택을 방어할 이유 3가지 |
| **02 리드 찾기** | 네 가지 경로: 통관 데이터, SNS, 검색, 전시회 | 하루 검증된 리드 20곳 이상 |
| **03 바이어 검증** | L1 선별 → L2 표준 → L3 심층 조사 | A/B/C 등급, 사기꾼 걸러내기 |
| **04 첫 연락** | 리드를 T0-T3로 나누고, 첫 연락은 세 채널로 | 등급별 리스트 + D0/D2/D5 후속 연락 계획(6일간 3회 연락) |
| **05 사양 협의** | 작은 요청부터. 가격은 언제나 마지막 | 사양 / 수량 / 도착 항구 |
| **06 견적과 협상** | 견적의 원칙: 모든 양보는 대가를 받아낸다 | 견적서 + 양보 단계 + 협상 화법 |
| **07 주문 이행** | 계약, 생산, 검품, 서류, 결제, 운송 | 이행 사이클 완결 + 재구매 계획 |

단계별 문서는 `docs/`에 단계당 한 파일씩 있으며, 모두 같은 여섯 부분 구조를 따릅니다([CONTRIBUTING.md](CONTRIBUTING.md) 참고). **이 단계의 목적 → 하나씩 따라 하는 방법 → 통과/탈락 기준 → 흔한 실수 → 복사해 쓰는 템플릿 → 이 단계용 AI 프롬프트.**

**완전히 처음이신가요?** [`docs/00-getting-started.md`](docs/00-getting-started.md)는 git도 Python도 모른다고 가정하고, 10분 정도면 움직이기 시작하게 해 줍니다. 오히려 급하신가요? [`docs/fast-path.md`](docs/fast-path.md)는 제로에서 첫 답장까지 7일 코스입니다.

## 30초 빠른 시작

**Python을 설치하기 싫으신가요?** 웹사이트를 여세요: [6hn68.github.io/zero-to-trade](https://6hn68.github.io/zero-to-trade/). 리드 점수, 영업 메일, 후속 연락 계획, 견적까지 브라우저 도구 네 가지를 12개 인터페이스 언어로 쓸 수 있습니다. CSV를 붙여 넣으면 T0-T3 등급이 나오고, 이어서 첫 연락, 후속 연락 날짜, 견적까지 나옵니다. 설치할 것도 없고, 브라우저 밖으로 나가는 것도 없습니다.

스크립트 파일 열다섯 개: 업무 스크립트 열네 개(그중 하나가 견적 엔진)와 개인정보 보호 스크립트 하나(`check_private_data.py`, 커밋 전에 실제 고객 데이터가 있는지 검사합니다). 표준 라이브러리만 사용합니다. Python 3.10+.

```bash
# 1. 리드 등급 나누기. CSV를 넣으면 T0-T3가 나오고, 등급마다 다음 행동이 붙습니다.
python scripts/lead_score.py examples/leads_example.csv

# 2. 한 등급용 영업 메일 초안 작성. 영문과 中文을 나란히.
python scripts/outreach_gen.py examples/leads_example.csv --tier T0

# 3. 후속 연락 계획 세우기. 세 번의 연락, 실제 날짜로.
python scripts/followup_plan.py --tier T0 --start 2026-10-08 --csv examples/leads_example.csv

# 4. 견적: 원가 + 운임 + 마진 -> FOB/CIF 가격대 + 3단계 양보안.
python scripts/quote_engine.py --cost 28 --freight 6 --margin 15
```

첫 번째 명령을 샘플 리드 10곳에 실행하면 실제로 이렇게 출력됩니다. 스크립트는 중국어로 출력하며, 【示例】는 "샘플"이라는 표시일 뿐이고, 마지막 열은 여기서 번역해 두었습니다.

| 등급 | 회사 | 국가 | 점수 | 다음 행동 |
|---|---|---|---|---|
| T0 | 【示例】海湾轮胎贸易 | 사우디아라비아 | 95 | 오늘 첫 연락 발송, 미루지 말 것 |
| T0 | 【示例】三角洲轮胎 | 사우디아라비아 | 88 | 오늘 첫 연락 발송, 미루지 말 것 |
| T1 | 【示例】阿曼蓝海 | 오만 | 77 | 이번 주 안에. 문구는 오늘 준비 |
| T1 | 【示例】半岛汽车 | 사우디아라비아 | 71 | 이번 주 안에. 문구는 오늘 준비 |
| T1 | 【示例】尼罗河商贸 | 이집트 | 67 | 이번 주 안에. 문구는 오늘 준비 |
| T1 | 【示例】迪拜轮毂行 | 아랍에미리트 | 65 | 이번 주 안에. 문구는 오늘 준비 |
| T1 | 【示例】利雅得汽配 | 사우디아라비아 | 60 | 이번 주 안에. 문구는 오늘 준비 |
| T2 | 【示例】尼日利亚先锋 | 나이지리아 | 50 | 콜드 풀, 하루 한 번 훑어보기 |
| T3 | 【示例】黎凡特供配 | 레바논 | 24 | 정보 부족, 연락처와 수요부터 찾을 것 |
| T3 | 【示例】利雅得零件店 | 사우디아라비아 | 17 | 정보 부족, 연락처와 수요부터 찾을 것 |

요약: **T0:2 / T1:5 / T2:1 / T3:2**. 오늘 연락: 【示例】海湾轮胎贸易, 【示例】三角洲轮胎. 이번 주: 【示例】阿曼蓝海, 【示例】半岛汽车, 【示例】尼罗河商贸, 【示例】迪拜轮毂行, 【示例】利雅得汽配. 당분간 보류: 【示例】黎凡特供配, 【示例】利雅得零件店.

CSV 헤더:

```
company,country,product,source,email,phone,years,contact,note
```

필수 항목은 `company`뿐입니다. 나머지는 비워 둬도 되며, 빈칸은 최저점으로 계산됩니다. 점수를 가장 크게 움직이는 것은 `source`입니다: `referral` / `trade_show` / `customs` / `linkedin` / `search`.

열다섯 개 스크립트 모두 `--help`를 지원합니다. `lead_score.py`에는 `--format json`과 `--country` / `--product` 필터도 있어서, 스프레드시트로 바로 넘길 수 있습니다.

스크립트는 기계가 판단할 수 있는 것만 판단합니다. 이메일이 있는가, 웹사이트가 있는가, T0 기준을 넘는가. 그 리드가 당신의 오후를 쓸 가치가 있는지는 문서에, 그리고 당신의 머릿속에 있습니다.

## 왜 방법론 문서만이 아니라 스크립트인가

"비즈니스용 AI" 저장소 대부분은 똑같습니다. 방법론을 프롬프트에 붙여 넣고 출시. 이 저장소는 거꾸로 갑니다. **원칙이 먼저, 도구는 그다음.**

이유는 이렇습니다. **프롬프트를 잘 쓰는 것과 무역을 잘하는 것은 다릅니다.** 제가 보기에 당신에게 부족한 건 표현이 아닙니다. 판단하는 방법입니다. 그래서:

- **여기서는 규칙이 곧 제품입니다.** T0에는 오늘 메일을 보냅니다. T3는 석 달 동안 서랍에 넣어 둡니다. 아무것도 받아내지 못한 양보는 협상이 아니라 선물입니다. 이런 판단을 대신 내려 줄 모델은 없습니다.
- **양이 많은 일은 AI에게.** 리드 8곳을 한 번에 선별하고, 50개 회사의 3단계 배경 조사 초안을 쓰고, 7일 치 후속 연락 변형을 뽑아내는 일. 몇 시간짜리 작업이지만 판단은 거의 들어가지 않습니다.
- **반복되는 일은 전부 스크립트로.** 등급 분류가 감이라면 그건 기준이 아닙니다. 그래서 의존성 제로, 200줄 미만의 스크립트로 만들었고, 두 사람이 돌려도 같은 답이 나옵니다.

경계선은 이렇습니다. **`if/else`로 쓸 수 있는가? 스크립트로. 저울질이 필요한가? 문서로. 사람이 쓴 것처럼 들려야 하는가? `prompts/`로.**

pandas도, OpenAI SDK도 없습니다. 일부러 뺐습니다. 초보자는 환경 설정에서 포기합니다. 수출을 처음 하는 사람은 고객을 찾는 것보다 `pip install`에 더 많은 시간을 잃게 되는데, 그런 데서 사람을 잃는 건 어리석은 일입니다.

## 기여하기

여기서 비어 있는 건 문서가 아닙니다. **나라별 현장의 디테일**입니다. 중동으로 가는 첫 타이어 주문이 어떻게 흘러가는지는 압니다. 하지만 에콰도르의 건축자재 유통이 어떻게 돌아가는지, 나이지리아 세관이 실제로 어떤 서류를 원하는지는 전혀 모릅니다. 그건 그곳에 팔고 있는 사람만 채울 수 있습니다.

참여 방법은 세 가지, 쉬운 것부터:

1. **고치기.** 오타, 낡은 정보, 무슨 말인지 모를 규칙. 이슈를 열어 주세요. 한 문장이라도 침묵보다 낫습니다. 템플릿은 세 가지를 묻습니다. 어느 줄에서 길을 잃었는지, 어느 숫자에 출처가 없는지, 어느 규칙이 당신의 업계에서는 통하지 않는지.
2. **한 단계 번역하기.** 스페인어, 아랍어, 포르투갈어, 러시아어, 프랑스어, 베트남어 — 실제로 쓰는 언어라면 무엇이든. 여섯 부분 구조는 그대로 두고 언어만 바꾸되, 용어는 [GLOSSARY.md](GLOSSARY.md)와 맞춰 주세요.
3. **당신의 나라나 업계 추가하기.** 바로 이것이 빠진 부분입니다. 해야 한다고 생각하는 것 말고, 직접 해 본 것을 써 주세요. 항목명, 서류명, 유통 채널이 어떻게 짜여 있는지, 어떻게 돈을 내는지, 그리고 왜 돈 내기를 거부하는지.

코드도 환영합니다. 단, 철칙이 하나 있습니다. **Python 3.10+, 표준 라이브러리만.** 이유는 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.

## 개발자분들께: 마음껏 뜯어고칠 수 있고, 의존성은 없습니다

업무 스크립트 열네 개(`lead_score` / `outreach_gen` / `followup_plan` / `quote_engine` / `due_diligence` / `tire_pack` / `landed_cost` / `trade_show` / `nudge` / `anchor_price` / `fast_path` / `market_rules` / `daily_video_list` / `fulfillment_checklist`)와 개인정보 보호 스크립트 `check_private_data.py`는 모두 표준 라이브러리만 사용합니다. `pip install`은 없습니다. 포크하고, 고치고, 당신의 도구에 그대로 넣으세요.

- 가중치가 마음에 안 드시나요? `lead_score.py` 맨 위의 상수 네 개(`CONTACT_W / SOURCE_W / SIGNAL_W / MATURITY_W`)를 바꾸면 됩니다. 그래도 최대 100점입니다.
- 자체 통관 데이터가 있으신가요? 헤더(`company,country,product,source,email,phone,years,contact,note`)만 맞추면 그대로 넣을 수 있습니다.
- 당신의 도구 안에 넣고 싶으신가요? 모든 스크립트는 깔끔하게 import됩니다. `score_lead()`, `render()`, `plan_followups()`, `build_quote()`는 dict와 list를 돌려주는 순수 함수입니다. 네트워크도, 파일 쓰기도 없습니다.
- CI는 PR마다 `py_compile`, 테스트 스위트(Python 3.10–3.13), 개인정보 검사 게이트를 돌리므로, 잘못된 수정이 슬쩍 들어올 수 없습니다.

> 여기서 지향하는 것은 **영리함보다 검증 가능성**입니다. 제 말을 믿지 마세요. `python scripts/lead_score.py examples/leads_example.csv`를 실행하고 나오는 결과를 직접 읽어 보세요.
